# NOTES — learner preferences

## Who
- Beginner. No prior ML coursework.
- Can read/write code.
- Math is rusty: linear algebra, calculus, probability all need rebuilding.
- Goals: course grade **and** one shipped project.

## How I want to be taught
- One topic per turn. Stop after the retrieval check; wait for "next".
- No preamble, no motivational filler, no recap of the recap.
- Mechanism first, then a worked example with real numbers. If a formula appears, it gets used immediately.
- Tables and bullets over paragraphs.
- Tell me the trap explicitly. I would rather be warned than surprised.

## Hard constraints
- Do not re-teach what MISSION.md lists as known.
- Every lesson must end with active recall, never a summary.
- Lessons must open offline (no CDN fonts/JS).
- If a mistake I make reveals a wrong mental model, correct the model, not just the answer.

## Build pipeline (added 2026-11-12)
- `tools/build_index.py` — dashboard; reads CURRICULUM.md, never hand-edit index.html.
- `tools/patch_lessons.py` — injects lesson id + top bar + script; idempotent.
- `tools/inject_colab.py` — appends the Colab block from the matching notebook.
- `tools/build_notebooks.py` — 35 notebooks from `tools/nb_data_a.py`; each cell is executed before writing.
- `tools/make_cheatsheets.py` — 10 PDFs, compiled with tectonic at /tmp/tectonic.
- `tools/make_decks.py` — 10 pptx from the lesson text; notes = mechanism section.
- `tools/build_site.py` — copies a publishable subset into `site/` (preserves `.git`).
- Deploy: commit inside `site/`, `git push`; Pages serves `main` root.

## Constraints learned
- No system LaTeX: use the tectonic binary at /tmp/tectonic (re-download if missing).
- System python lacks numpy/pptx: use `.venv/bin/python` for notebook/deck builds.
- Pages CDN caches `assets/course.js`; bump `?v=N` when changing it.
