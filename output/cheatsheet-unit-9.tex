\begin{multicols}{2}
\normalsize

\sect{Protocol}
1. broadcast $w_t$ \ 2. local SGD $\times E$ \ 3. upload $w_t^k$ \ 4. aggregate\\
$w_{t+1}=\sum_k\dfrac{n_k}{n}w_t^k$ \quad $n=\sum_k n_k$\\
Communication is the bottleneck: rounds $\times$ clients $\times$ model size.

\sect{Non-IID}
Client drift: local optima diverge; the average fits nobody.\\
FedProx: $F_k(w)+\dfrac{\mu}{2}\|w-w_t\|^2$ \ (larger $\mu$ $\Rightarrow$ stronger leash)\\
$E\uparrow$ $\Rightarrow$ fewer rounds, more drift. Not monotone.\\
Report per-client accuracy; a high mean can hide a small client.

\sect{Privacy}
DP: $P(M(D)\in S)\le e^\varepsilon P(M(D')\in S)+\delta$\\
DP-SGD: clip per-example gradient to $C$, add $\mathcal{N}(0,\sigma^2C^2)$\\
Budget composes over rounds (10 $\times$ 0.1 $\approx$ 1.0 basic).\\
Secure aggregation: server sees only the sum; no protection from malicious clients.

\sect{Threats}
membership inference, gradient inversion, poisoning, backdoor\\
Defences: clipping + noise, robust aggregation (median/trimmed), update inspection

\sect{Gotchas}
\begin{itemize}
\item Federated $\neq$ private. Gradients are a fingerprint.
\item FedAvg $\neq$ pooled training unless clients are IID.
\item More local epochs is not free: drift grows with $E$.
\end{itemize}
