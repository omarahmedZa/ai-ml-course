\sect{Text to IDs}
Token $\neq$ word. English $\approx$ 4 chars/token $\approx$ 0.75 words.\\
Code $\approx$ 1.7 tokens/word; base64 far worse.\\
BPE: start from characters, merge the most frequent adjacent pair.

\sect{Embeddings}
$E\in\mathbb{R}^{V\times d}$; token $i\mapsto E[i]$ (a lookup, not a matmul)\\
$\cos(u,v)=\dfrac{u\cdot v}{\|u\|\|v\|}$ \quad length is not meaning\\
Static (Word2Vec) vs contextual (transformer): one vector per \emph{occurrence}

\sect{Recurrence}
$h_t=\tanh(W_h h_{t-1}+W_x x_t+b)$ \quad state is fixed size\\
BPTT $=$ product of $T$ Jacobians: $0.9^{20}=0.12$\\
LSTM: $c_t=f\odot c_{t-1}+i\odot g$, \ $h_t=o\odot\tanh(c_t)$\\
Additive cell path $\Rightarrow$ gradient near identity.

\sect{Seq2seq}
encoder $x_{1:n}\to h_n$; \ decoder $p(y_t\mid h_n,y_{<t})$\\
Teacher forcing at train, free-running at test $\Rightarrow$ exposure bias\\
Bottleneck: 600 tokens into 512 floats $=0.85$ floats/token.

\sect{Gotchas}
\begin{itemize}
\item Truncating by characters can split a token.
\item Attention weights are not causal explanations.
\item LSTM mitigates decay; it does not remove the bottleneck.
\end{itemize}
