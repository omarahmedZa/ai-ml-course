\sect{Axes}
intrinsic (by design) vs post-hoc (after training)\\
global (model) vs local (one prediction)\\
audience decides: applicant, operator, regulator

\sect{Attribution}
Saliency: $\partial f/\partial x_i$ --- one pass, saturates, not complete.\\
Integrated gradients: $\int_0^1 \partial f(\alpha x)/\partial x_i\,d\alpha$; complete vs baseline.\\
LIME: sparse linear surrogate on perturbations; unstable across seeds.\\
SHAP: $\phi_i=\sum_{S\subseteq F\setminus i}\dfrac{|S|!(|F|-|S|-1)!}{|F|!}[v(S\cup i)-v(S)]$\\
Efficiency: $\sum_i\phi_i=f(x)-f(\text{baseline})$.

\sect{Faithfulness tests}
Deletion: remove top-$k$ attributed features $\Rightarrow$ output must drop.\\
Insertion: add least-to-most $\Rightarrow$ recovery speed.\\
Randomisation: shuffle weights $\Rightarrow$ map must change (else it is an edge detector).\\
Stability: re-run explainer $\Rightarrow$ same ranking?

\sect{Gotchas}
\begin{itemize}
\item Correlation $\neq$ causation: attribution is about the function, not the world.
\item SHAP splits credit between correlated features; neither is ``the cause''.
\item Plausible $\neq$ faithful. Humans reward smooth maps.
\end{itemize}
