First time · about 5 minutes

Set up the problem runner

You need Python and one file. After this page, every problem is: pull, edit, run, submit.

What you need— the whole list

  • Python 3.10 or newer — python3 --version should print 3.10+.
  • A terminal — Terminal (macOS/Linux) or PowerShell (Windows).
  • NumPy — only some problems need it; install it now and forget it.
  • Internet once — to download dml.py and each problem. After that, run works offline.

Step 1 — install Python and NumPy— once per machine

# macOS (Homebrew) or Linux
brew install python          # macOS
sudo apt install python3 python3-pip   # Debian/Ubuntu

# Windows: install from python.org, tick "Add python.exe to PATH"

# all systems
python3 -m pip install numpy

Check both:

python3 --version
python3 -c "import numpy; print(numpy.__version__)"

On Windows the command is usually py instead of python3. Use py in every command below.

Step 2 — download dml.py— one file, no install

mkdir ~/ml-problems && cd ~/ml-problems
curl -O https://omarahmedza.github.io/ai-ml-course/dml.py

# no curl? open the URL in a browser and save the file here.
# Windows PowerShell:
#   Invoke-WebRequest https://omarahmedza.github.io/ai-ml-course/dml.py -OutFile dml.py

Check it:

python3 dml.py doctor

You should see your Python version, NumPy, site reachable, and work writable. If any line fails, the fix is in the troubleshooting table below.

Step 3 — pull your first problem— a starter and its tests

python3 dml.py pull 001

This creates:

ml-problems/
  dml.py
  work/001/
    solution.py     ← you edit this
    tests.py        ← the tests, readable
    STATEMENT.md

Step 4 — edit, run, submit— the loop you repeat

# open work/001/solution.py in any editor and write the function
python3 dml.py run 001        # per-test pass/fail
python3 dml.py submit 001     # score + a link and a token

You will see:

Score 5.0/5 on attempt 1 (best 5.0/5)
Open:  https://…/problems/001.html#r=…
Paste: eyJ2IjoxLCJpZCI6IjAwMSIs…~8f3a1c2d

Open the link, or copy the token into the problem page. The page checks the token's checksum and stores the score in this browser. That is what verified locally means: the site cannot prove your run, it can only check that the token was not altered.

How scoring works— no surprises

RuleValue
Points per problem5
Visible tests40% of the score
Hidden tests60% of the score
Attempt decay−10% per failed submit, floor 50%
Best scorekept; attempts keep counting

Troubleshooting— the five usual failures

MessageFix
python3: command not foundWindows: use py. macOS: brew install python. Linux: sudo apt install python3.
No module named numpypython3 -m pip install numpy (or py -m pip install numpy).
could not download …No internet or a proxy. Clone the repo once and use --bundle-dir repo/problems/data on every command.
Permission deniedYou are in a read-only folder. cd ~ and make a work folder there.
Token rejectedCopy it again from the Paste: line — a partial copy fails the checksum.

Offline mode— no network at all

git clone https://github.com/omarahmedZa/ai-ml-course
cd ml-problems
python3 dml.py pull 001 --bundle-dir ../ai-ml-course/problems/data
python3 dml.py submit 001 --bundle-dir ../ai-ml-course/problems/data --no-open

The bundle directory contains every problem's statement and tests, so nothing is downloaded.

Ready. Pick a problem and follow steps 3–4. If a lesson points at a problem, its number is the same as the lesson's.
