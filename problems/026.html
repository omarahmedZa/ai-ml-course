Write attention(query, keys, values) returning the output vector for one query.

  • score each key by q . k / sqrt(len(q))
  • softmax the scores per row (subtract the max before exponentiating)
  • return the weighted blend of the value vectors, one float per value dimension

Raise ValueError when keys is empty, a key's length differs from len(query), or the number of values differs from the number of keys. Do not mutate the inputs.

With q = [1, 0], k1 = [1, 0], k2 = [0, 1], v1 = [10, 0], v2 = [0, 10] the weights are 0.670 / 0.330 and the output is [6.70, 3.30].
