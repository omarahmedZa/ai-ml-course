Debug the nearest-neighbour vote

Classical Mlread the lesson →

knn_predict(points, labels, query, k) should take the nearest k points and return the majority label.

The current implementation uses the farthest points. Fix it, and add the missing checks:

  • raise ValueError if k < 1, if k > len(points), or if labels and points differ in length
  • distances are Euclidean
  • return the label as given (do not convert it)

Starter

import math


def knn_predict(points, labels, query, k):
    """Return the majority label among the k nearest points."""
    d = [math.dist(p, query) for p in points]
    order = sorted(range(len(points)), key=lambda i: d[i])
    nearest = order[-k:]          # BUG: this takes the farthest k
    votes = {}
    for i in nearest:
        votes[labels[i]] = votes.get(labels[i], 0) + 1
    return max(votes, key=votes.get)
