Write value_iteration(n_states, actions, next_state, reward, gamma, tol=1e-9) for a deterministic MDP.

  • actions[s] is the list of legal actions in state s; an empty list is terminal
  • next_state[(s, a)] is the next state and reward[(s, a)] its reward
  • apply V(s) = max_a [r + gamma * V(s')] until the largest change is below tol
  • return a list of n_states floats
  • raise ValueError when gamma is outside [0, 1]

Terminal states keep value 0.0.
