UCB with unpulled arms

One function, checked against hidden tests. Run it locally, paste the token back.

Reinforcement Learningread the lesson →

ucb_scores divides by zero when an arm has never been pulled, and it never checks its inputs. Fix it.

  • return float('inf') for any arm with counts[i] == 0
  • otherwise return mean + sqrt(2 * log(sum(counts)) / count)
  • raise ValueError if the two lists have different lengths
  • raise ValueError if the total number of pulls is zero
  • return a list of floats

import math


def ucb_scores(means, counts):
    """Return the UCB index for each arm."""
    t = sum(counts)
    scores = []
    for m, n in zip(means, counts):
        bonus = math.sqrt(2 * math.log(t) / n)   # BUG: n can be zero
        scores.append(m + bonus)
    return scores
