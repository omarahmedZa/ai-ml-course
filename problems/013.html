clip_gradient should clip by norm: if the gradient's Euclidean length exceeds max_norm, scale the whole vector down to that length; otherwise leave it alone.

The current implementation is wrong. Fix it without changing the signature.

  • the direction must be preserved; only the length changes
  • max_norm <= 0 raises ValueError
  • return floats and do not mutate grad

Clipping only caps how far a step can travel; a short gradient passes through untouched.

The contract

def clip_gradient(grad, max_norm=1.0):

Starter

import math


def clip_gradient(grad, max_norm=1.0):
    """Scale grad down so its norm is at most max_norm."""
    norm = math.sqrt(sum(x * x for x in grad))
    return [x / norm for x in grad]   # BUG: always rescales, even when short
