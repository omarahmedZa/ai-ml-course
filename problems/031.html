Shapley by averaging orderings

One function, checked against hidden tests. Run it locally, paste the token back.

Explainabilityread the lesson →

Write shapley_values(value_fn, n) returning the exact Shapley value of each of n players.

  • value_fn takes a frozenset of player indices and returns the coalition's value
  • for each of the n! orderings, add each player's marginal gain as it joins
  • average the gains over all orderings and return a list of n floats in player order
  • return [] for n == 0, and raise ValueError for n < 0

Use itertools.permutations; the tests use at most four players, so at most 24 orderings. The parts must add up to value_fn(all players).
