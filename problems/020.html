One Bellman backup sweep

One function, checked against hidden tests. Run it locally, paste the token back.

Reinforcement Learningread the lesson →

Write backup_all(values, transitions, gamma) for one sweep of policy evaluation.

  • values holds the current V(s), one entry per state
  • transitions is aligned with values; each entry is (reward, next_index)
  • a next_index of -1 marks a terminal state, so that state gets only its reward
  • otherwise return reward + gamma * values[next_index]
  • return a list of floats, same length as values, and do not mutate it

Raise ValueError when gamma is outside [0, 1], when the two lists differ in length, or when a non-terminal index is out of range.
