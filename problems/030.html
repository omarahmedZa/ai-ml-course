The applicant's reasons, only

One function, checked against hidden tests. Run it locally, paste the token back.

Explainabilityread the lesson →

applicant_reasons should return the reasons an applicant can act on.

Each term is (name, contribution) in log-odds; actionable is the set of names the applicant can change. The function must

  • keep only actionable terms - selection, not simplification
  • rank those by absolute contribution, largest first
  • return at most k names, ties keeping their input order
  • raise ValueError when k < 1

The starter filters *after* it slices, so a large income term eats a slot and the applicant is told nothing they can change. Fix it and keep the signature.

Starter

def applicant_reasons(terms, actionable, k=2):
    """Return the k largest-magnitude contributions the applicant can act on."""
    ranked = sorted(terms, key=lambda pair: -abs(pair[1]))[:k]
    return [name for name, _ in ranked if name in actionable]
