BPE encode by replaying merges

One function, checked against hidden tests. Run it locally, paste the token back.

Nlp Transformersread the lesson →

Write bpe_encode(word, merges) that replays an ordered merge list, as a tokenizer does at inference.

  • start from the characters of word
  • apply merges in the given order; for each pair (left, right), scan left to right and replace every adjacent left, right with the single symbol left + right
  • a symbol cannot be reused inside one pass: left to right, no overlap
  • later merges see the symbols produced by earlier ones
  • return the final list of symbols; "" returns []
  • do not mutate merges

The order is the algorithm; nothing is counted at encode time.
