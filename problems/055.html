Discounted returns, backwards

discounted_returns walks the rewards forwards, so G_t is built from the wrong tail. Fix it.

  • return G_t = r_t + gamma * G_{t+1} for every step, in the original order
  • return [] for empty input
  • raise ValueError when gamma is outside [0, 1]
  • return a list of floats

def discounted_returns(rewards, gamma):
    """Return G_t for each step, discounted by gamma."""
    total = 0.0
    out = []
    for r in rewards:          # BUG: walks forwards
        total = r + gamma * total
        out.append(total)
    return out
