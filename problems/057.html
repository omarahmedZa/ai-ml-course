brier_score(probs, labels) already works. Add expected_calibration_error(probs, labels, bins=10) returning the weighted average gap between confidence and observed frequency.

  • bin index is min(int(p * bins), bins - 1), so p == 1.0 lands in the last bin
  • for each non-empty bin, gap is abs(mean(probs) - mean(labels)) and weight is count / n
  • ECE is the sum of weight * gap

Raise ValueError if the sequences differ in length, are empty, bins < 1, or any probability lies outside [0, 1]. Do not change brier_score.

    total = 0.0

        total += (p - y) ** 2
    return total / len(probs)
