prox_point(w_global, w_local, mu) should return where one FedProx client stops.

Minimising 0.5 (w - w_local)^2 + (mu/2) (w - w_global)^2 gives the fixed point (w_local + mu * w_global) / (1 + mu).

  • mu is the leash stiffness: 0 means no leash, large mu stays near w_global
  • raise ValueError when mu is negative
  • return a float

The starter has the coefficients swapped, so the leash pulls toward the client's own optimum instead of the global model. Fix it and keep the signature.

def prox_point(w_global, w_local, mu):
    """Return the fixed point of the FedProx local objective."""
    if mu < 0:
        raise ValueError("mu must be non-negative")
    return (mu * w_local + w_global) / (1.0 + mu)
