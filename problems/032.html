Problem 032 · debug

Deletion test against random

One function, checked against hidden tests. Run it locally, paste the token back.

ExplainabilityEvaluation Metricsread the lesson →

is_faithful(clean, deleted, deleted_random, margin=0.05) should say whether an explanation's deletion test beats deleting random features of the same count.

  • clean is the score with nothing removed
  • deleted is the score after removing the top-k attributed features
  • deleted_random is the score after removing k random features
  • return True only when the drop from the attributed features exceeds the random drop by at least margin
  • raise ValueError for any score outside [0, 1], or for a negative margin

The starter compares the raw drop with margin and never asks what random removal costs - which is how a decorative heatmap passes review.

The contract

def is_faithful(clean, deleted, deleted_random, margin=0.05):

Starter

def is_faithful(clean, deleted, deleted_random, margin=0.05):
    """Return True when deleting attributed features costs more than random."""
    for score in (clean, deleted, deleted_random):
        if not 0.0 <= score <= 1.0:
            raise ValueError("scores must lie in [0, 1]")
    if margin < 0:
        raise ValueError("margin must be non-negative")
    return clean - deleted > margin
