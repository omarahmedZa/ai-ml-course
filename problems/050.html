Write attention_weights(q, keys) for one attention head.

  • q is a query vector and keys is a list of key vectors
  • raise ValueError when keys is empty or any key's length differs from len(q)
  • score each key with the dot product divided by sqrt(len(q))
  • return the softmax of those scores as a list of floats, summing to 1
  • use a numerically stable softmax (subtract the maximum score)

Do not mutate the inputs.
