sigmoid(z) is already defined. Add preference_loss(pairs) returning the mean Bradley-Terry loss over preference pairs.

  • each pair is (r_better, r_worse), two reward-model scores
  • the loss on one pair is -ln sigmoid(r_better - r_worse)
  • raise ValueError for an empty list
  • return a float, and stay stable when the score gap is huge

Only the difference matters: moving both scores by the same amount leaves the loss unchanged.
