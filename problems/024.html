DQN target, terminal fixed

dqn_target builds the target r + gamma * max Q(s', .) from the frozen target network.

  • when done=True the target is just reward — a terminal state has no future
  • raise ValueError when next_q is empty and the transition is not terminal
  • return a float

The starter bootstraps past terminal states, crediting finished episodes with value that does not exist. Fix it and keep the signature.

The contract

def dqn_target(reward, gamma, next_q, done=False):

Starter

def dqn_target(reward, gamma, next_q, done=False):
    """Target for one transition, built from the frozen target network."""
    return reward + gamma * max(next_q)
