Standardise without leaking

One function, checked against hidden tests. Run it locally, paste the token back.

standardize(train, test) is supposed to scale every column using the mean and standard deviation of the training rows only (divide by n, and use 1.0 when a column has zero spread).

It currently computes its statistics from train + test, so the test rows leak into the transform. Fix it.

  • keep the signature and the return shape: (scaled_train, scaled_test)
  • raise ValueError for an empty training set or a row with the wrong number of columns
  • do not mutate either input

def standardize(train, test):
    """Scale columns using the mean and std of the training rows."""
    rows = train + test
    n = len(rows)
    d = len(rows[0])
    means = [sum(r[j] for r in rows) / n for j in range(d)]
    stds = []
    for j in range(d):
        var = sum((r[j] - means[j]) ** 2 for r in rows) / n
        stds.append(var ** 0.5 or 1.0)

    def scale(data):
        return [[(r[j] - means[j]) / stds[j] for j in range(d)] for r in data]

    return scale(train), scale(test)
