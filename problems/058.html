Nearest-rank percentile, off the end

percentile(values, q) should return the nearest-rank percentile: sort ascending, set rank = ceil(q / 100 * n), and return the value at that 1-based position as a float.

The starter uses a floor index, so p50 is off by one and p100 crashes. Fix it. Raise ValueError for an empty sequence or a q outside (0, 100]. Do not mutate values.

The contract

Starter

import math


def percentile(values, q):
    """Return the nearest-rank q-th percentile of values."""
    xs = sorted(values)
    return xs[int(q / 100 * len(xs))]
