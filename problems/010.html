linear_grads(x, w, b, y) should return (dL/dw, dL/db) for the graph z = wx + b, L = (z - y)^2.

Upstream is dL/dz = 2(z - y); multiply it by each local slope: dL/dw = dL/dz * x, dL/db = dL/dz * 1.

The starter forgets the local slope of the multiply. Fix both gradients and keep the signature.

The contract

def linear_grads(x, w, b, y):

Starter

def linear_grads(x, w, b, y):
    """Return (dL/dw, dL/db) for L = (w*x + b - y) ** 2."""
    z = w * x + b
    upstream = 2.0 * (z - y)
    return upstream, upstream  # BUG: dw must be scaled by x
