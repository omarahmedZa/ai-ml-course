Symmetric INT8 quantization

Write quantize_int8(values) returning (codes, scale) for symmetric per-tensor INT8.

  • scale = max(abs(v)) / 127
  • each code is round(v / scale), clamped to [-127, 127], stored as an int
  • an all-zero input returns all-zero codes and scale == 0.0

Raise ValueError for an empty sequence. Return the codes in input order and do not mutate values. A code restored as q * scale must be within scale / 2 of the original.
