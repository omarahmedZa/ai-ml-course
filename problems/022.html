Q-learning update, sign fixed

Reinforcement Learningread the lesson →

q_update should move q a fraction alpha of the way toward the Q-learning target reward + gamma * next_max.

  • next_max=None marks a terminal transition, so the target is just reward
  • raise ValueError when alpha is outside [0, 1]
  • return a float

The starter adds the target to q instead of moving toward it. Find the bug, fix it, and keep the signature.

The contract

def q_update(q, reward, gamma, next_max, alpha):

Starter

def q_update(q, reward, gamma, next_max, alpha):
    """Return Q(s, a) after one Q-learning update."""
    return q + alpha * (reward + gamma * next_max)
