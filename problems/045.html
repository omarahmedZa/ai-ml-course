2-D convolution with stride and padding

conv1d already computes a valid 1-D convolution. Add conv2d(image, kernel, stride=1, padding=0) for a square kernel.

  • slide the kernel over the image with the given stride
  • pad with zeros: padding rows/columns on every side
  • each output cell is the sum of elementwise products over its patch
  • output side: (H + 2*padding - k) // stride + 1
  • raise ValueError when stride < 1, when the kernel is not square, or when the kernel is larger than the padded image

Do not change conv1d.

def conv1d(signal, kernel):
    """Valid 1-D convolution, stride 1."""
    k = len(kernel)
    return [sum(signal[i + j] * kernel[j] for j in range(k))
            for i in range(len(signal) - k + 1)]
