What's inside this course

Eight kinds of material, one loop: read, look, drag, run, answer, score. This page tells you where each one lives.

1 · Lessons

Each of the 35 topics is one page, about 1,400 words, split into eight fixed sections: why it matters, the one core idea, how it works in parts, worked examples, the trap, a retrieval check, runnable code, and extra practice.

Every part is short. No block is longer than 60 words, and a figure or a number sits beside almost every claim.

2 · Figures

There are 85 figures. Some are static diagrams; some are charts you can change.

3 · Equation labs

There are 42 short labs. Each isolates one symbol of an equation, gives it a figure, and takes about three minutes.

You find them inside a lesson, right under the formula they belong to, as a compact grid of nine (or fewer) buttons. They are worth 4 points each.

Example: the objective θ* = argmin… has nine labs — θ, f_θ(xᵢ), L, the atom, Σ, 1/n, argmin, θ*, and the whole thing.

4 · Animations

Six pages animate, and only where motion is the idea: descent, the forward pass, the backward sweep, a hidden state updating, attention weights flowing, and one federated round.

Every animation has play, pause, a scrubber and a restart. If your system asks for reduced motion, it shows the final frame instead of moving.

5 · Code

Each lesson ends with a Colab block: a notebook split into six sections, with an explanation above every code cell, every line commented, and a collapsible “Line by line” list after it.

Every notebook has a matplotlib plot, an interactive slider that redraws it, and a section showing what breaks. NumPy, matplotlib and ipywidgets only — no installs, no GPU.

7 · Downloads

Ten cheat sheets (PDF, one side each) and ten slide decks (PPTX, speaker notes included), linked from the dashboard and from the bottom of every lesson.

8 · How to use it

  1. Open a topic, read it with the answers closed.
  2. Drag every figure; change one number and predict what happens before you look.
  3. Answer the retrieval check, then the practice questions.
  4. Click the lab grid if a symbol still feels abstract.
  5. Run the Colab cell; break it on purpose.
  6. Move on only when you can explain the idea without the page open.
