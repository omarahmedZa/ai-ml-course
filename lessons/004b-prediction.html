The objective, one symbol at a time · Lab 2

f_θ(xᵢ) — one prediction

You can read the subscript correctly and turn one row into one number.

Where this sits

θ* = argminθ (1/n) Σi L(fθ(xi), yi)

Lab 2 of 9 · the whole expression is dimmed; only the prediction is lit

The objective compares a prediction against a truth, once per row, then adds up the prices. This lab is only the first half of that comparison: the number the model produces before anyone grades it.

Notice that θ carries no i. The weights are shared by every row, which is why the sum can walk from row to row while the model stays the same.

Read it out loud

Say it as three pieces. f is the model — here, a straight line. θ (theta) is everything the model learned: the weight w and the bias b. xᵢ (x-sub-i) is one row of data, the i-th example, fixed before training starts.

So f takes two things: a row, and the weights it is currently carrying. fθ(xi) reads as "the model, with parameters θ, applied to row i". The θ is a subscript on f because it belongs to f.

That ordering is the whole point. The row is the input; the weights are the machine doing the reading. A different machine reads the same row differently.

One row, one number

With w = 2 and b = 1, the model is fθ(x) = 2x + 1. Feed it the middle row, xᵢ = 2, and it answers 5. That single number is fθ(xi) — not the loss, not the truth, just the prediction.

fθ(xi) = w·xi + b = 2(2) + 1 = 5

The point does not move when you drag a slider. Only the line does, and the prediction is the line's height above that point. Nothing you do to w or b edits the data.

That vertical gap between point and line is what a loss will later price. For now, watch only the height.

Three rows, three numbers, one unchanged θ. Now the last row is yours — same two operations, and the final step is hidden.

Check the last row

fθ(10) = 2(10) + 1 = 21. The weights never changed between rows; only the input did.

The trap

Most common wrong mental model

"The subscript applies to x." It does not. The symbol is fθ — the model carrying parameters θ — applied to xᵢ. The row is data: measured, fixed, and unaware of θ.

Correction: read outward from f. The θ hangs off f. The row sits inside the parentheses.

The tell: if changing the data seemed to change θ, you are reading the notation backwards. θ stays put until a training step moves it.

Retrieval check

  1. With w = 3 and b = 0, what is fθ(2)?
    Answer

    6. The model is 3x + 0, and 3 × 2 = 6. The weights did the work; the row only supplied the 2.

  2. You replace the row but keep θ. What changes?
    Answer

    The prediction changes. θ is untouched — same weight, same bias, a different number out because a different row went in.
