Supervised learning as function fitting

You can write down (X, y, f_θ, L) for any supervised task and say what is being learned.

Why this matters

Every model in this course — a spam filter, a translation system, a Q-network — is this same four-part object. Name the four parts and you can read a paper's method section instead of guessing at it.

The one core idea

Supervised learning chooses parameters θ so that f_θ maps inputs X to targets y with minimum average loss L — on data you have, hoping it holds on data you don't.

How it actually works

ObjectShape / typeSpam example
X — inputsn × d matrix10,000 emails × 2 features
y — targetsn × 1 vector1 = spam, 0 = ham
f_θ — modeld → 1σ(w·x + b)
L — lossscalarbinary cross-entropy
  • Hypothesis class = the set of functions f_θ you allow. Linear models can only draw straight boundaries; a 3-layer net can draw curved ones. Choosing the class is choosing what is learnable.
  • Empirical risk = average loss on the training set. Training minimises it.
  • What is learned is θ, not the data. With 10,000 emails and 3 parameters, the model compresses 10,000 rows into 3 numbers.
θ* = argmin_θ (1/n) Σᵢ L(f_θ(xᵢ), yᵢ)

Worked example

1. One email, end to end

Features: x = [1, 50] = "contains 'free'" (1), "length in words" (50). Parameters w = [2, −0.01], b = −1.

StepValue
z = w·x + b2(1) + (−0.01)(50) − 1 = 0.5
p = σ(z)0.622
Loss if y = 1−ln 0.622 = 0.475
Loss if y = 0−ln 0.378 = 0.973

The prediction is "62% spam". Training's job is to nudge w and b until spam-like emails get high p and ham-like ones get low p.

2. Reading a new paper

Given "we fine-tune a transformer with cross-entropy on 1M labelled pairs", the four objects are immediate: X = token IDs, y = next token, f_θ = transformer, L = cross-entropy. If you cannot fill a cell, that is the question to ask about the paper.

The trap

Most common wrong mental model

"The model learned the data." It learned parameters. A model with more parameters than data points can score perfectly and still be useless — it memorised X without learning the mapping from X to y.

The hidden assumption: future data comes from the same distribution as training data (i.i.d.). Break that — a new hospital, a new year, a shifted user base — and a perfect training score means nothing. Topic 5 is entirely about this gap.

Step by step

If the mechanism above went past you, walk it one click at a time. Each step is one sentence and one idea.

Retrieval check

  1. For "predict house price from 8 features", name all four objects with shapes.
    Answer

    X: n×8 · y: n×1 continuous · f_θ: a linear model or gradient-boosted trees · L: squared error. If L were classification loss, you would be answering a different question.

  2. Your model gets 100% training accuracy and 71% test accuracy. Is it a good model?
    Answer

    No. The 29-point gap says it memorised rather than generalised. The 71% number is the only one that describes the deployed system.

  3. What does changing the hypothesis class change — the data, the loss, or what the model is capable of representing?
    Answer

    Only the last one. Data and loss can stay identical while moving from linear to tree to neural, and the achievable functions change completely.
