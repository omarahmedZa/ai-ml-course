Value functions & the Bellman equation

You can write V and Q and explain the recursive expectation.

Why this matters

"How good is this state?" is the question every RL algorithm answers. The Bellman equation turns that unanswerable question into a fixed-point computation — and it is guaranteed exam material.

The one core idea

The value of a state equals the reward you get now plus the discounted value of where you land. That is a recursive expectation: value is defined in terms of itself, one step ahead.

How it actually works

V^π(s) = Σ_a π(a|s) Σ_{s′} P(s′|s,a)[ R(s,a,s′) + γ V^π(s′) ]
FunctionQuestionShape
V^π(s)Expected return starting in s, following π|S|
Q^π(s,a)Expected return after taking a in s, then π|S|×|A|
V*(s)Best possible value; V* = max_a Q*(s,a)|S|
  • Relationship: V^π(s) = Σ_a π(a|s) Q^π(s,a). V averages Q over the policy's choices.
  • Optimality: Q*(s,a) = Σ_{s′} P[R + γ max_{a′} Q*(s′,a′)]. The max is what makes it optimal rather than policy evaluation.
  • Terminal states have V = 0; the recursion stops there.
  • TD learning turns the expectation into a sample: V(s) ← V(s) + α[r + γV(s′) − V(s)]. The bracket is the TD error.

Worked example

1. One backup

State s, action a gives reward 1 and lands in s′ with V(s′) = 2. γ = 0.9:

TermValue
Immediate reward1.0
Discounted future0.9 × 2 = 1.8
Q(s,a)2.8

If s has two actions with Q = 2.8 and Q = 1.5, then V*(s) = 2.8 and the optimal policy picks the first. One backup, one decision.

2. Why bootstrapping is legitimate

The true value would require summing over every possible future. The Bellman equation replaces that infinite sum with one step plus an estimate of the rest — an estimate plugged into an estimate. It is biased (the estimate is wrong early), but converges because the recursion is a contraction: each backup reduces the error by a factor of γ.

The trap

Most common wrong mental model

"V and Q are the same thing." V is per state; Q is per state–action pair. You cannot choose an action from V alone without a model of the dynamics. Q-learning learns Q precisely so that argmax needs no model.

Second trap: bootstrapping off a terminal state. There is no future after termination; using γV(s′) there adds phantom value and inflates every trajectory that ends.

Retrieval check

  1. r = 0, γ = 0.9, V(s′) = 5. What is Q(s,a)?
    Answer

    0 + 0.9 × 5 = 4.5. The whole value is deferred — which is exactly why discounting matters for long horizons.

  2. Why does the optimal Bellman equation contain a max while the policy-evaluation one contains a sum over actions?
    Answer

    Evaluation averages over the policy's action distribution. Optimisation asks what the best action would give, so it maximises instead of averaging.

  3. What is the TD error, and what does its sign tell you?
    Answer

    r + γV(s′) − V(s): the surprise between the bootstrapped target and the current estimate. Positive means the state was undervalued; negative, overvalued.
