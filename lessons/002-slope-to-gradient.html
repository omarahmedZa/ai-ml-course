Slope → gradient

You can compute a gradient and explain why training steps against it.

Why this matters

Every training loop in this course — backprop, Q-learning, PPO — is the same sentence: measure the slope, step the other way. If the gradient is a mystery, every optimizer you meet is a mystery too.

The one core idea

A gradient is the slope of the loss with respect to every parameter at once. It points uphill, so learning means stepping downhill — subtract it.

How it actually works

  • Derivative = local slope of a 1-D function: (f(w+h) − f(w)) / h as h → 0. It answers "if I nudge w, how much does f move?"
  • Partial derivative = the same question with every other variable frozen.
  • Gradient ∇f = the vector of all partials. Its direction is steepest ascent; its length is how steep.
  • The update: w ← w − η∇f. η is the learning rate — how far you trust the slope.

In deep learning f is the loss over millions of parameters. Backprop (topic 10) computes that whole gradient in one backward pass — it is bookkeeping on the chain rule, not a new kind of math.

Worked example

1. One parameter

f(w) = w², so f′(w) = 2w. Start at w = 3, η = 0.1:

2. Two parameters

f(x, y) = x² + 3y at (2, 1):

With η = 0.1: (2, 1) → (1.6, 0.7). Loss moves from 4 + 3 = 7 to 2.56 + 2.1 = 4.66. Check the direction: y felt a constant push of 3, so it moves every step until it hits a boundary — f is linear in y, with no minimum there.

The trap

Most common wrong mental model

"The gradient points downhill." It points uphill — toward increasing loss. Adding the gradient makes training worse, which is exactly why the update has a minus sign.

Second trap: too large a step. On f(w) = w² with η = 1, w = 3 → 3 − 6 = −3, and the loss returns to 9. Repeat forever: the parameters oscillate and nothing converges.

Step by step

If the mechanism above went past you, walk it one click at a time. Each step is one sentence and one idea.

Retrieval check

  1. f(w) = 3w² at w = 2. Compute the gradient and one step with η = 0.1.
    Answer

    f′ = 6w = 12. w ← 2 − 0.1(12) = 0.8. Loss falls from 12 to 3(0.64) = 1.92.

  2. You have the gradient of the loss. Why subtract it rather than add it?
    Answer

    Because it points toward higher loss. Subtracting moves toward lower loss locally. The minus sign is the whole algorithm; everything else is choosing η.

  3. f(x, y) = x + y² at (1, 3). What is ∇f, and which parameter will keep moving forever?
    Answer

    ∇f = (1, 6). x keeps moving: f is linear in x, so the gradient never shrinks. y settles at 0, where its gradient vanishes.

Build it in Colab

Runnable, NumPy-only, no setup: open the notebook in Colab · local copy. The cell prints numbers, not pictures — change one value and rerun to see what breaks.

import numpy as np
f = lambda w: w ** 2
grad = lambda w: 2 * w
w, lr = 3.0, 0.1
for step in range(4):
    print(f"step {step}: w={w:7.4f}  loss={f(w):8.4f}  grad={grad(w):7.4f}")
    w -= lr * grad(w)
