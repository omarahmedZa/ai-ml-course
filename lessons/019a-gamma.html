Topic 19 · the return is dimmed; only the discount is lit

A reward is paid at one moment. A return is the whole stream of rewards, and γ (gamma) is the number that shrinks each one once more for every step you wait. It always sits between 0 and 1.

Only γ is lit in the strip above. Everything around it is the return that γ is quietly rewriting.

What the discount does

At γ = 0.9, a reward one step away counts 0.9 of face value; two steps away 0.81; ten steps away 0.35. The same coin, collected later, buys less. Move the slider and watch the staircase flatten — the curve is γk, the fraction of a reward surviving k steps of delay.

Two limits

γ = 0 is total myopia: only the next reward counts, so every action with a delayed payoff looks like doing nothing at all. Push γ toward 1 and the agent grows patient. At exactly 1 in a task that never ends, the return can grow without bound. Most training sits between 0.9 and 0.99.

One episode, three discounts

Ten unit rewards, one per step, and nothing else changes. Undiscounted they total 10. At γ = 0.9 the return is 6.5; at 0.99 it is 9.6; at 0.999 the bar sits within a hair of 10. The rewards never move — only the discount does.

Reward is not return

A reward is one number at one moment. A return already contains the whole future, discounted. "The agent maximises reward" is shorthand for maximising return, and the shorthand hides the only part γ controls: how much the future is allowed to vote.

Faded example

Two rewards, γ = 0.5. Take 4 now and 4 one step later: 4 + 0.5 × 4 = 6. Now do the next two rows with the final step removed.

Row 2: 2 + 0.5 × 8 = 6. Row 3: γ = 0 deletes the second reward entirely, so the return is 2. Discounting is not a tie-breaker; at γ = 0 it removes the future from the sum.

The trap

Most common wrong mental model

"γ is a technicality for making the infinite sum converge." Convergence is a side effect, not the job. γ is a design statement about urgency: it decides how large a delayed payoff must be before the agent prefers it to a small reward now.

Correction: treat γ as part of the task, written next to the reward. Two agents with identical rewards and different γ learn visibly different behaviour, and both are correct for their own objective.

The tell: at γ = 0.9, a reward of 11 arriving after 100 steps is worth about 0.0003. An agent maximising that return takes 1 now, every time — and a report that blames the reward function has missed the discount.

Retrieval check

  1. A reward of 1 at each of three steps, γ = 0.5. What is the return?
    Answer

    1 + 0.5 + 0.25 = 1.75. Undiscounted it would be 3, so the two steps of delay cost 1.25.

  2. What behaviour does γ = 0 produce?
    Answer

    Myopic: only the next reward matters. Any delayed payoff is multiplied by zero, so planning disappears and the agent grabs whatever pays immediately.
