Two solution families: value vs policy

You can contrast Q-learning and policy gradient on what they learn and when each fails.

Why this matters

Every algorithm you will read about for the rest of this course is one of two things, or a hybrid of both. That single fact tells you, before any tuning, whether the method can reuse yesterday's data and whether it can cope with a wheel that turns by degrees rather than clicks.

The distinction is also the first thing a reviewer will ask about: "is this off-policy?" is a question about data budget, not fashion. Pick badly and the symptom is concrete. A Q-learning agent on a seven-joint robot arm must solve an optimisation over a continuous action space at every single step, just to pick its move, which makes the control loop orders of magnitude slower than the policy it replaced. Pick the other way and a replay buffer of stale actions quietly biases a policy-gradient update. In an exam, one table with five rows answers half the questions on this topic.

The one core idea

There are two routes to good behaviour. Price every move and always take the cheapest-looking one: that is value-based learning, and the thing learned is a map of payoffs. Or adjust the habit directly, making whatever worked more likely next time: that is policy-based learning, and the thing learned is a reflex.

In one line: learn the scoreboard, or learn the reflex — and actor–critic learns both at once. With Q = 0.5, r = 1, γ = 0.9, next-state Q′ = 0.8 and α = 0.1, the target is 1.72, the error 1.22, and the new Q is 0.622.

Q(s,a) ← Q(s,a) + α[ r + γ max_{a′} Q(s′,a′) − Q(s,a) ]

Price every move and act greedily, or raise the probability of whatever worked — actor–critic learns both at once.

How it actually works

Seven parts, moving from what both families share to the update rule each one uses.

Part 1 — Both maximise expected return

Expected return is the probability-weighted total of discounted future rewards. Every method in this unit is an estimator for it, and every loss function you meet is a proxy for it. Why this part exists: without one shared objective there is no way to compare the families at all. They disagree about representation, not about what counts as success.

Part 2 — Value-based methods learn a scoreboard

A value-based agent stores Q(s,a) for each pair and acts by argmax, the action with the largest estimate. Tabulated on a 5×5 grid with four moves, that is 25 × 4 = 100 numbers. Why this part exists: if Q were exact, greed on it would be optimal, so learning Q is sufficient — the policy, the rule that picks actions, is a by-product that needs no representation of its own.

Part 3 — The max in the target makes it off-policy

Q(s,a) ← Q(s,a) + α[ r + γ max_{a′} Q(s′,a′) − Q(s,a) ]

The bracket holds the target minus the current estimate; the difference is the TD error, meaning the surprise between prediction and outcome. The max asks what the best next action would give, regardless of what the agent actually did. Why this part exists: that independence is what lets the update learn from actions nobody would choose again, including random ones from an untrained policy.

Part 4 — Off-policy means data keeps its value

Because the target ignores the behaviour policy, one stored transition can be replayed many times — 10 updates from one sample instead of one. Why this part exists: samples are the scarce resource. A robot arm costs seconds per transition and a simulator costs money, so reusing each one tenfold is the difference between a project that finishes and one that does not.

Part 5 — Policy-based methods learn the reflex

Here the policy is a parameterised function π_θ(a|s), often a neural network that outputs action probabilities or a mean action, and training nudges θ so that high-return behaviour becomes more probable. Why this part exists: no argmax is ever taken, so a continuous action needs no search. The network emits the action in one forward pass, however many dimensions it has.

Part 6 — The estimator is log-probability times return

θ ← θ + α ∇_θ log π_θ(a|s) · G_t

With π(left) = 0.7 and a return of 5 after choosing left, the log-probability gradient is scaled by 5 and left becomes more likely; a return of −5 pushes it back down. Why this part exists: the return is only a number, and ∇ log π is the one route from a scalar score to a change in a probability. It also means the reward never has to be differentiable.

Part 7 — Actor–critic swaps the return for an advantage

Replace G_t with Q(s,a) − V(s), the advantage: how much better this action was than the state's average. With Q = 2.8 and V = 2.41, the advantage is 0.39. Why this part exists: a raw return mixes "this state is good" with "this action was good", so every action in a lucky episode gets pushed up. Subtracting the baseline isolates the action and removes most of the noise.

Worked example

1. Two Q-learning updates on the same transition

Q = 0.5, r = 1, γ = 0.9, max Q′ = 0.8, α = 0.1. Apply the update twice.

UpdateTargetTD errorNew Q
11 + 0.9(0.8) = 1.721.72 − 0.5 = 1.220.5 + 0.1(1.22) = 0.622
21 + 0.9(0.8) = 1.721.72 − 0.622 = 1.0980.622 + 0.1(1.098) = 0.732

What to notice. The target stayed at 1.72 because the next state's values were held fixed, so each update closes 10% of the remaining gap and the sequence approaches the target geometrically: 0.5, 0.622, 0.732. It never overshoots, and with α = 1 it would arrive in a single jump. Off-policy here is not a slogan: update 2 learned from a transition the agent did not take again.

2. One policy-gradient step, both directions

π(left) = 0.7, so the logit is ln(0.7/0.3) = 0.847. For a two-action softmax, the gradient of log π(left) with respect to the logit is 1 − p = 0.3. Take α = 0.1.

Return after leftGradient 0.3 × GNew logitNew P(left)
+51.50.847 + 0.15 = 0.9970.731

What to notice. The size of the push depends on how surprising the action was: at p = 0.7 the factor is 0.3, but for a rare action at p = 0.05 it would be 0.95, more than three times larger. A habit barely moves; a surprise moves a lot. The same action with the opposite return moves the probability the other way, which is what makes the estimator unbiased rather than merely optimistic.

3. The advantage as a within-state comparison

Same state, V = 0.7 × 2.8 + 0.3 × 1.5 = 2.41, with two actions available.

ActionQQ − Vπ × advantage

What to notice. The policy-weighted advantages sum to exactly zero, which is the proof that subtracting V changes nothing in expectation — it only rescales what each action contributes. That is why the baseline is free variance reduction. It is also why the advantage cannot be gamed by a state simply being good: it is measured against that state's own average.

The trap

Most common wrong mental model

"Q-learning is strictly better because it reuses data." It feels right: reuse is free efficiency, and tabular Q-learning comes with a convergence proof, so more reuse looks like strictly more of a good thing.

Correction: the proof covers tables, not networks. Combine off-policy data, bootstrapping and function approximation and you get the deadly triad of topic 23 — divergence, not convergence. Policy-gradient methods give up reuse and buy stability; PPO dominates real-world continuous control for that reason, not because it is more sample-efficient.

Second trap: assuming a policy gradient needs a differentiable reward. The gradient flows through log π, so a win, a loss, or a human rating is enough.

The tell: check the age of the actions in your buffer. If the policy producing them is dozens of versions old while the loss falls smoothly and episode return stays flat, you are optimising against a policy that no longer exists. The other tell is a continuous-action project where the wall clock is dominated by an inner optimiser: that is a max being solved numerically, and a policy network would have emitted the action directly.

Retrieval check

  1. You have a robot arm with 7 continuous joints. Which family, and why?
    Answer

    Policy gradient (or actor–critic). argmax_a Q(s,a) over a continuous 7-D action space requires solving an optimisation at every step; a policy outputs the action directly.

  2. Why can Q-learning learn from transitions generated by an old, bad policy?
    Answer

    Its target uses max_{a′} Q(s′,a′), which is independent of the behaviour policy. The update asks "what would the best action give", not "what did I do".

  3. What does the advantage Q − V add over raw return G?
    Answer

    It subtracts the baseline: "better than average here" instead of "good in absolute terms". Same expected gradient, much lower variance.

import numpy as np
Q, r, gamma, alpha = 0.5, 1.0, 0.9, 0.1
target = r + gamma * 0.8
print("Q-learning: target", target, "TD error", round(target - Q, 2),
      "new Q", round(Q + alpha * (target - Q), 3))
