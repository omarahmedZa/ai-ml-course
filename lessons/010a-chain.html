Equation lab · backpropagation

The chain rule — one slope at a time

You can turn a slope measured at the loss into a slope at a weight by multiplying the local slopes along the path.

Where this sits

∂L/∂w = ∂L/∂z · ∂z/∂w = 2(z − y)·x

Lab 1 of 2 · the two local slopes are lit; the multiplication between them is the whole rule

∂ means "a small change in". ∂L/∂w is the slope of the loss with respect to one weight: how much L moves when w moves a little. Backprop obtains it without a second forward pass, by reusing slopes already measured in the network.

Slopes in series multiply

Suppose z changes three times as fast as w, and L changes twice as fast as z. Then L changes six times as fast as w, because 3 × 2 = 6. Rates in series multiply. That sentence is the chain rule, and every backward pass is a long product of such rates.

The network gives you each factor separately. The loss node knows ∂L/∂z = 2(z − y). The weighted-sum node knows ∂z/∂w = x and ∂z/∂b = 1. Neither node knows the whole answer.

The walk, with numbers

Take one example: x = 2, w = 3, b = 1, truth y = 10. The model predicts z = wx + b = 7, so the residual is 7 − 10 = −3.

Reading the two gradients

Both gradients are negative: raising either value raises the loss, so gradient descent subtracts and increases w and b. They start from the same −6, but w carries an extra factor of x = 2, so it moves twice as far. That factor is not importance; it is the input sitting in the path.

One step lands on the truth

With learning rate η = 0.1: w ← 3 − 0.1(−12) = 4.2 and b ← 1 − 0.1(−6) = 1.6. The new prediction is 4.2·2 + 1.6 = 10, so the loss is zero. That exactness belongs to this quadratic, not to training in general.

Check the hidden derivative

−4: multiply the loss slope −2 by the local slope x = 2. Note that the gradient shrank from −12 to −4 as the prediction approached the truth; slopes are local, not fixed properties of a weight.

The trap

Most common wrong mental model

"The gradient for a weight is just 2(z − y), the same as the loss slope." It feels right because that is the number the loss node hands over, and it has the correct sign and rough size.

Correction: the loss slope still has to cross the weighted sum, which multiplies it by x. Forget that factor and every weight gets the same gradient, so inputs stop mattering.

The tell: double x from 2 to 4 with w, b and y unchanged. The loss and ∂L/∂z are identical, but ∂L/∂w must double. If your number does not move, a local slope went missing.

Retrieval check

  1. With x = 2, w = 3, b = 1, y = 10, what is ∂L/∂b?
    Answer

    −6: ∂L/∂z = −6 times ∂z/∂b = 1. The bias has no input to scale it.

  2. Why is ∂L/∂w twice ∂L/∂b here?
    Answer

    Because ∂z/∂w = x = 2 while ∂z/∂b = 1. The same incoming slope is multiplied by a different local slope on each path.
