Equation lab · backpropagation

Fan-out — gradients add, they do not compete

You can combine the gradients arriving from two branches into one number for the value they share.

Where this sits

∂L/∂u = ∂L/∂a + ∂L/∂b = 3 + 4 = 7

Lab 2 of 2 · the sum is lit; each branch's own contribution is the dim part

u is a value used twice: once by branch A, once by branch B, and both branches reach the loss. When u moves, the loss moves for two reasons at once, so the backward pass must report both.

Two paths, one nudge

Forward, the same array leaves u along two edges. Backward, each edge returns a gradient, and the node that owns u receives two numbers rather than one. Only the last step changes: what to do with the pair.

Change u by a tiny amount. Branch A's output shifts, and branch B's output shifts. The loss moves by A's contribution plus B's contribution. Nothing is shared out and nothing is averaged: each branch reports the full effect of the nudge along its own route.

The numbers

Branch A sends 3 and branch B sends 4, so ∂L/∂u = 7. With η = 0.1 the update is u ← u − 0.1 × 7. A branch sending zero — a ReLU clamped shut, a masked path — adds zero and changes nothing, while the surviving branches still report their full amounts.

Why not multiply

Multiplication belongs to slopes in series, where one quantity feeds the next. Here the branches are parallel: two routes from the same u to the same loss. Serial slopes multiply; parallel contributions add.

Where it shows up

A weight used at two positions in a sentence, a residual connection that bypasses a block, an embedding shared by two output heads, the same parameter appearing twice in one expression. In each case one value feeds several branches, and a dropped branch shrinks the gradient with no error message.

The trap

Most common wrong mental model

"Two gradients for one value should be averaged, to be fair to both paths." It feels right because averaging is how you combine two estimates of the same quantity.

Correction: these are not two estimates of one effect; they are two separate effects that both really happen. Averaging halves the step for that value alone, which behaves like a lower learning rate on some weights and not others.

The tell: switch one branch off and re-run. The total should fall by exactly that branch's number. If it falls by half of everything, someone averaged.

Retrieval check

  1. u feeds two branches that send −5 and +2. What is ∂L/∂u?
    Answer

    −3. Signs are kept while adding; a branch pushing the loss down can cancel one pushing it up.

  2. Why is the answer not 3 × 4 = 12?
    Answer

    Because the paths are parallel, not serial. Multiplication combines slopes along one route; addition combines separate routes to the same value.
