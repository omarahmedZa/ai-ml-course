The objective, one symbol at a time · Lab 8

θ* — optimal for what?

You can say what θ* is relative to, and why it is not the true parameters.

Where this sits

θ* = argminθ (1/n) Σi L( fθ(xi), yi )

Lab 8 of 9 · the whole expression is dimmed; only the answer is lit

θ* (theta-star) is the θ that makes the average loss smallest. It is an answer to a question, not a fact about the world. Change the question and the same symbol points somewhere else.

The pieces: θ is every number the model learns, L is the price of one wrong prediction, and J(θ) is that price averaged over all rows. Training searches the θ axis for the lowest point of J.

Best is a relationship

θ* is not a property of the model sitting alone. It is the point where one loss, applied to one set of rows, bottoms out. Two inputs, one output.

What θ* depends onWhat it does not
The data — the fixed pairs (xi, yi) you were givenThe truth — whatever weights the world actually uses
The loss L — the rule that prices each missAnother dataset — collect new rows and the bottom moves
The shape of fθ — what the model is allowed to expressHow long you trained — that finds θ*, it does not define it

Notice what the left column never mentions: being right about reality. θ* is defined entirely inside the learning problem you wrote down, using the rows you happened to have.

Change the data, move the bottom

Two datasets, one model, one loss. Press a button: the curve is J(θ), the total loss at each candidate θ. The lowest point of the curve is θ*.

Note the floor as well as the position. Even at its lowest the curve sits above zero: J* = 1 for A and J* = 2.5 for B. The best θ still pays something, and that residue is what this model cannot explain.

Change the loss, move it again

Hold the data still and swap the loss. Squared loss chases the mean, because squaring gives a far-off row a huge vote. Absolute loss chases the median: it counts distance, so an extreme row gets one vote like any other.

Take the rows 1, 2, 3, 4, 100. The mean is 22, the median is 3. With squared loss θ* = 22. With absolute loss θ* = 3. Same rows, same model, and θ* moves by 19.

Faded example

Dataset A has J(θ) = (θ − 2)² + 1. A square is smallest at zero, so θ* = 2 and J* = 1. Do dataset B the same way, with the last step removed.

The bracket is zero at θ = 4, so θ* = 4, and the leftover constant is J* = 2.5. The position came from the data; the height came from how well this model can fit it.

The trap

Most common wrong mental model

"θ* is the true parameter." No. θ* is the best fit for this data and this loss — the argmin of a function you chose, over rows you happened to collect.

Correction: θ* minimises your stated objective. A different objective, or a larger sample, can hand you a different θ*, and both answers were optimal for their own problem.

The tell: if adding rows changes θ*, it was never "the truth." Truth does not move when you collect more evidence; a sample mean does.

Retrieval check

  1. Dataset B bottoms at θ = 4. What is θ*?
    Answer

    4. The bottom is the definition: θ* is wherever J is smallest, and dataset B's smallest point sits at θ = 4.

  2. You add one huge outlier and keep squared loss. Does θ* move?
    Answer

    Yes, toward the outlier. Squaring gives that row a large vote, so the mean — and θ* — slides its way. Switch to absolute loss and θ* barely budges.
