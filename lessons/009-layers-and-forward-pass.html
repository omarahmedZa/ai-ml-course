Layers and the forward pass

You can trace shapes and values through a two-layer network by hand.

Why this matters

Shape errors cause more failed training runs than bad ideas. If you can walk a batch through a network on paper, you can read a stack trace and know which matrix is wrong before running anything.

The one core idea

A forward pass is a sequence of affine maps (Wx + b) separated by elementwise nonlinearities. Each layer changes the shape in a predictable way; nothing else happens.

How it actually works

  • Layer ℓ: zˡ = Wˡaˡ⁻¹ + bˡ, then aˡ = φ(zˡ). z is pre-activation, a is activation.
  • Shape rules: if layer ℓ has nˡ units and the previous has nˡ⁻¹, then Wˡ is nˡ × nˡ⁻¹ and bˡ is nˡ. Outputs are column vectors.
  • Batching: stack examples as rows, X is B × n⁰. Then Zˡ = Aˡ⁻¹(Wˡ)ᵀ + bˡ and shapes become B × nˡ. The batch dimension is never mixed.
  • The bias broadcasts across the batch: one vector added to every row.
  • Depth = number of weight matrices. Width = units per layer. Capacity grows with both, but depth composes features (edges → shapes → objects).

Worked example

1. Two inputs, one example

x = [1, −1], W¹ = [[1, 2], [−1, 0]], b¹ = [0, 1], ReLU, then W² = [1, 1], b² = −0.5.

Note what the ReLU destroyed: both hidden units were at or below zero, so the entire input information vanished. This example is one dead network away from "why is my loss stuck at 0.69?"

2. The same pass as a batch

Four examples: X is 4 × 2. W¹ is 2 × 2, so A¹ = ReLU(X(W¹)ᵀ + b¹) is 4 × 2. Then W² is 1 × 2: output 4 × 1.

(4×2)(2×2) → (4×2) → (4×2)(2×1) → (4×1)

Every row is independent. That independence is exactly what mini-batch training exploits: one matrix multiply processes 256 examples at once.

The trap

Most common wrong mental model

"The nonlinearity is optional detail." Drop it between two layers and topic 8's proof applies: the stack collapses. A suspiciously linear loss curve often means a missing activation.

Second trap: mixing up Wx and xWᵀ when batching. Both can be "right" numerically for square matrices and silently wrong otherwise. Write the shapes down before the code.

Retrieval check

  1. Layer 1: 10 units. Layer 2: 5 units. What are the shapes of W², b², and the output for a batch of 32?
    Answer

    W² is 5 × 10, b² is 5, output is 32 × 5. The batch dimension only appears at the edges, never in the weights.

  2. In the worked example, why did the network output exactly 0.378 regardless of the input's second feature?
    Answer

    Both ReLU units were clipped to 0, so z² = b² = −0.5 for every input. The hidden layer stopped transmitting information; only the bias survived.

  3. Where does the parameter count for a layer come from?
    Answer

    nˡ × nˡ⁻¹ weights plus nˡ biases. A 512 → 512 layer has 262,144 + 512 = 262,656 parameters.

Build it in Colab

Runnable, NumPy-only, no setup: open the notebook in Colab · local copy. The cell prints numbers, not pictures — change one value and rerun to see what breaks.

import numpy as np
x = np.array([1., -1.])
W1, b1 = np.array([[1., 2.], [-1., 0.]]), np.array([0., 1.])
z1 = W1 @ x + b1
a1 = np.maximum(0, z1)
W2, b2 = np.array([1., 1.]), -.5
z2 = W2 @ a1 + b2

Extra practice

Two harder questions. Three attempts each — the answer unlocks only after the third miss. Correct on the first try is worth 2 points, later 1, revealed 0.
