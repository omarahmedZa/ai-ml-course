The objective, one symbol at a time · Lab 4

L(f_θ(xᵢ), yᵢ) — the atom

You can turn one row into one loss, in two steps, without skipping the first.

Where this sits

θ* = argminθ (1/n) Σi L( fθ(xi), yi )

Lab 4 of 9 · the whole term is lit; everything around it only repeats or combines it

Read the lit part as a sentence: the price of the model's answer on example i. The sum, the 1/n and the argmin invent nothing new. Everything later in the objective only combines copies of this term.

The result has its own name: ℓᵢ, one loss, for one example. This lab is about producing that number and nothing else.

Two steps, one number

Two things happen to a row, always in this order. First the model predicts. Then the loss prices that prediction.

Step 1 — predict. θ is every number the model learns. Applied to the input xᵢ, it returns a number written f_θ(xᵢ), or ŷ for short. With the course model ŷ = 2x + 1 and xᵢ = 3, that is 7. A prediction is a value, not yet a price.

Step 2 — price. L compares the prediction with the true answer yᵢ, subtracts, squares, and returns one number. Here (10 − 7)² = 9.

xᵢyᵢ (truth)ŷ (prediction)residual yᵢ − ŷloss L
310739

Five numbers on one row, and only the last is a loss. The other four are its inputs — which is why skipping step 1 leaves step 2 with nothing to price.

Note where the prediction sits: inside the brackets of L, as an argument. It is food for the price, not a rival to it.

The pipeline

Two of these boxes do work; the rest are values being carried between them.

Order matters. ŷ exists before L runs, and L sees one row only: not θ, not the other examples, not the average.

Three rows at once

Now a dataset of three rows, with the same two steps run on each row separately.

Rows 1 and 2 are free: prediction equals truth, so the price is zero. Row 3 misses by 4 and costs 16. One row can be perfect while another is expensive — the atom never averages them away.

Each ℓᵢ here was computed as if the other two rows did not exist. That isolation is the point of the word atom.

The objective will add 0 + 0 + 16 and divide by 3. An average of about 5.3, with no hint of which row caused it.

The trap— L(f_θ(xᵢ), yᵢ)

Most common wrong mental model

"The loss is computed on the average." No. The objective averages losses; the atom does not. Each ℓᵢ is computed from one row, alone, before any addition happens.

Correction: two rows give two prices. Add them afterwards if you like — but a loss divided by n before it exists is not a loss.

The tell: if you cannot write one ℓᵢ for one row, you are computing the objective, not the atom. Try it on a single row, with no n in sight.

Retrieval check— L(f_θ(xᵢ), yᵢ)

  1. Truth 5, prediction 2. What is the loss?
    Answer

    Residual 3, loss 3² = 9. Prediction first, then price.

  2. Which costs more, a residual of 3 or a residual of 4 — and by how much?
    Answer

    Residual 4 costs 16; residual 3 costs 9. The wider gap costs 7 more for one extra unit of error.
