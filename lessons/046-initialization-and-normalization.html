Initialization & normalization

You can pick a weight initialization, say what variance it preserves, and explain what normalization fixes.

Neural NetworksTraining Deep Nets

Why this matters— initialization

A deep network is a chain of matrix multiplies. Multiply the signal's spread by 1.5 per layer and ten layers give 57×; multiply by 0.5 and ten layers shrink it by 1,024×. Either way, most numbers leave the range where gradients are useful. Initialization picks that multiplier before training starts; normalization holds it near 1 while training runs. Both are one-line choices that decide whether a 40-layer model learns at all.

The failure it prevents. An exam asks why a 50-layer network with standard-normal weights will not train. "Vanishing gradients" earns half marks. The arithmetic earns the rest: with 256 inputs per neuron, a unit-variance weight turns a spread of 1 into 16, so the signal is exploding, not vanishing. In code the same gap is a loss that prints nan after a hundred steps, or activations that are exactly zero after every ReLU.

The one core idea— initialization

Conserve the spread. Write x for one input number, w for one weight, and n for how many inputs feed a neuron (its fan-in). The neuron sums n terms w·x. If the inputs have mean 0 and variance 1, and the weights have mean 0 and variance σ²(sigma) (sigma squared), that sum has variance n·σ². Setting σ² = 1/n makes the factor exactly 1, so the next layer receives the spread this one sent. That is Xavier initialization; He doubles the variance to pay for ReLU discarding half the values.

In one line: draw weights with standard deviation 1/√fan_in, and put the spread back whenever it drifts. At fan_in = 256 that is 1/16 = 0.0625, not 1.0 — a factor of sixteen per layer, which is the difference between a network that trains and one that does not.

std(w) = 1/√fan_in keeps the signal's spread

Variance out ≈ fan_in × variance(w) × variance in. Choose the weight variance to cancel the fan-in.

How it actually works— initialization

Six parts: the shapes, the symmetry problem, the variance rule, the two recipes, normalization, and where to place it.

Part 1 — Write down the shapes

A layer's weight matrix W has one row per output and one column per input, so its shape is fan_out × fan_in. Each output is a dot product of one row with the input, which is why the sum has exactly fan_in terms. Why this part exists: using the output size instead of the input size gives a scale wrong by the square root of their ratio.

Part 2 — Randomness breaks symmetry

If every weight starts at zero, every neuron computes the same output, receives the same gradient, and stays identical forever. A 512-neuron layer behaves like a one-neuron layer. Why this part exists: this is why initialization is random at all; a constant init fails for a structural reason, not a badly chosen number.

Part 3 — The variance rule

For independent zero-mean terms, variances add: n terms of variance σ² give n·σ². So the output standard deviation is √n · σ times the input's. With n = 256 and σ = 1 the spread grows 16-fold per layer, and after five layers it is 16⁵ ≈ 1,048,576. Why this part exists: it turns "unstable" into a number you can predict before running anything.

Part 4 — Xavier and He

Xavier uses variance 1/fan_in and suits tanh. He uses 2/fan_in because ReLU zeroes half its inputs and so halves the variance; doubling the weights compensates. Frameworks expose both as xavier_uniform_ and kaiming_normal_, usually with zero biases. Why this part exists: the wrong one is a factor-of-√2 error per layer — survivable at depth 5, fatal at depth 50.

Part 5 — Normalization puts the spread back

LayerNorm takes one example's feature vector, subtracts its mean, divides by its standard deviation, then applies a learned scale γ (gamma) and shift β (beta). BatchNorm does the same per feature, averaged over the batch. Why this part exists: initialization sets the scale once, but weights move and the scale drifts; normalization corrects every forward pass and so tolerates a larger learning rate.

Part 6 — Placement decides stability

Post-norm normalizes after the residual add, as in the original transformer. Pre-norm normalizes inside the branch and leaves the residual path clean, which trains reliably at 100 layers without warmup. Why this part exists: the same layer in a different position changes whether the gradient reaches layer 1 intact, so "we use LayerNorm" is not yet a stability claim.

The trap— initialization

Most common wrong mental model

"Normalization makes initialization irrelevant." It does not. LayerNorm repairs the forward scale, so a badly initialized network still produces sane activations — but the first gradient depends on the weights, and a zero init is still perfectly symmetric after normalization. Every neuron normalizes to the same values, receives the same gradient, and the layer never differentiates.

It feels right because the forward pass looks healthy. The damage has moved into the backward pass and the first update, where printing activations will not show it.

Correction: keep the jobs separate. Initialization sets the scale and breaks symmetry; normalization holds the scale and improves conditioning. Check gradient norm per layer at step 1: a healthy 50-layer net stays within about one order of magnitude across layers.

The tell: an activation-spread printout reading 1.0, 0.02, 3×10⁻⁴, 4×10⁻⁶ — about 50× per layer, which is a fan-in of 2,500 with unit weights. A second tell is nan after two steps at a small learning rate: that is the exploding direction, and the fix is dividing by √fan_in, not lowering the rate further.

Retrieval check— initialization

  1. A layer has 1,024 inputs and weights with standard deviation 0.01. What happens to the spread, and what would He use?
    Answer

    The spread is multiplied by √1024 × 0.01 = 0.32, shrinking about 3× per layer. He would use √(2/1024) = 0.0442.

  2. Why does a zero initialization stop learning even with LayerNorm?
    Answer

    All neurons in a layer compute identical outputs and receive identical gradients, so they stay identical. LayerNorm preserves that equality.

  3. What do γ and β add to plain standardization?
    Answer

    A learned scale and offset, so the layer can undo the normalization if useful. With γ = 1, β = 0 it is plain standardization.

Build it in Colab— initialization

Runnable, NumPy-only, no setup: open the notebook in Colab · local copy. Sections, plots and line-by-line notes — run the cells in order, then change one number and rerun.

import numpy as np
rng = np.random.default_rng(0)
x = rng.normal(size=(512, 256))            # 512 rows, fan_in = 256
for name, std in [("unit", 1.0), ("he", np.sqrt(2 / 256))]:
    w = rng.normal(0, std, size=(256, 256))
    h = np.maximum(x @ w, 0)               # ReLU
    print(f"{name:4s} std={h.std():.3f}")
