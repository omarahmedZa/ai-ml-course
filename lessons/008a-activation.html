Equation lab · the neuron

Why φ cannot be removed

You can show, with one small multiplication, that deleting the bend collapses a stack of layers into a single linear map.

Where this sits

ŷ = W2 φ( W1x + b1 ) + b2

Lab 1 of 1 · only the bend is lit; the two matrix products around it are ordinary linear layers

A neuron computes a weighted sum, then bends it. The bend is written φ (phi, say "fee"). This lab asks what happens to a whole network when φ is removed.

The bend is the only nonlinear part

W1x + b1 is linear: double every input and the sum doubles, scale one input and only its own term moves. φ is applied entry by entry, and it is not linear. Every departure from a straight line that a deep network can express enters through φ. Nothing else in the diagram can supply one.

Two layers, one matrix

Take W1 = [[1, 2], [3, 4]] and W2 = [1, −1], both biases zero. The deep model computes W2(W1x); multiply the matrices once and the brackets disappear.

W2W1 = [1·1 + (−1)·3, 1·2 + (−1)·4] = [−2, −2]. The pair of layers is the single row [−2, −2]: two sets of weights, one straight line.

RouteFirst stepSecond stepOutput at x = [1, 1]
Deep, two layersW1x = [3, 7][1, −1]·[3, 7] = −4−4
Collapsed, one rowW2W1 = [−2, −2][−2, −2]·[1, 1] = −4−4

Matrix multiplication is associative, so W2(W1x) = (W2W1)x. The second layer sees only a linear function of x, so it can rescale that function and nothing more. The two rows agree because one expression is the other, bracketed differently.

What the bend buys

With φ in place the model is piecewise: flat on one side of zero, sloped on the other. The weights decide which side an input lands on, so the network can switch behaviour by region. Squaring instead gives a curve rather than a corner — still one no single matrix imitates.

Depth without a bend

Fifty layers without φ still equal one matrix W. You pay for fifty multiplications, carry fifty layers of parameters, and own the power of one linear layer. Nothing errors; the loss simply settles where logistic regression would.

Check the hidden row

With W2 = [1, 1] the collapse is [1·1 + 1·3, 1·2 + 1·4] = [4, 6]. Deep: W1x = [3, 7], then 3 + 7 = 10. Collapsed: 4 + 6 = 10. Both routes must agree; no bend sits between them.

The trap

Most common wrong mental model

"Depth adds power by itself; the activation only makes training faster." It feels right because deeper networks do perform better, and the activation looks like plumbing.

Correction: depth adds power only when something between the layers is nonlinear. Remove φ and the product of matrices is a matrix; the depth buys parameters and nothing else.

The tell: count the nonlinearities, not the layers. Twelve layers with zero activation calls is a linear model wearing twelve coats.

Retrieval check

  1. With W1 = [[1, 2], [3, 4]] and W2 = [1, 1], what single row replaces the two layers?
    Answer

    [4, 6]: 1·1 + 1·3 = 4, and 1·2 + 1·4 = 6. One row, one linear map.

  2. Why does a ReLU between the layers stop the collapse?
    Answer

    Because max(0, z) is not of the form c·z: it is zero below and equal to z above. No single matrix reproduces that split, so the product rule no longer applies.
