Part of Topic 24 · DQN — where the target network is introduced

DQN, one mechanism at a time · Lab 1

r + γ max Q(s′,a′) — the frozen answer key

You can compute a Q-learning target from frozen weights, and say why freezing it keeps the error meaningful.

Where this sits

target for one transition = r + γ maxa′ Qθ⁻(s′, a′)

Lab 1 of 2 · θ⁻ is a frozen copy of θ; the tick is not a minus sign

Q-learning does not learn a prediction directly. It learns a prediction that should match a target, and the target is built from the prediction itself. This lab is about the copy that stops that loop chasing its own tail.

One transition, one target

A transition is one row of experience: state s, action a, reward r, next state s′. Qθ(s,a) is the model's estimate of all reward still to come after taking a in s. The target is the number that estimate should have been.

With r = 1, γ = 0.9 and the frozen network's best next-state value max Q(s′,a′) = 0.8, the target is 1 + 0.9 × 0.8 = 1.72. γ (gamma) is the discount: a reward one step away counts 90% as much as a reward now.

Why a moving target destabilises

If the same weights θ write both the guess and its target, every update moves the number being aimed at. The gap closes more slowly, and a learner that appears to improve can leave the error almost unchanged.

Same three updates, same learning rate. Frozen, the error falls 1.22 → 0.89. Moving, it falls only to 1.13, because each step also lifted the target by 0.09.

Sync every 10,000 steps

Keep a second copy θ⁻ and copy θ into it every 10,000 steps. Between copies the target is a constant, so the update becomes ordinary regression: predict a fixed number and shrink the gap.

The price is staleness. For up to 10,000 steps the key is out of date and may be wrong in one consistent direction. That is a bounded error you can measure; a target rewritten every step is not.

The trap— r + γ max Q(s′,a′)

Most common wrong mental model

"A target network stabilises training, so it must be the fix for any unstable run." It feels right because the loss visibly calms down once θ⁻ is added. But the frozen copy removes one fault: a target that moves with the weights. Correlated frames, an oversized learning rate, or a reward scale that dwarfs Q will still break the run, and freezing repairs none of them.

Correction: name the fault first. Moving target → freeze it. Correlated data → shuffle a buffer. Large errors → cap the loss.

The tell: loss falls smoothly, evaluation return rises, then collapses, and reloading an earlier checkpoint recovers the run. That signature is a target that outran its predictions, not a learning rate slightly too high.

Retrieval check— r + γ max Q(s′,a′)

  1. r = 2, γ = 0.5, max Q(s′,a′) = 4. Compute the target.
    Answer

    2 + 0.5 × 4 = 4.0. The reward is not discounted; only the future term is.

  2. Why does the target network not make the update unbiased?
    Answer

    θ⁻ is stale by up to 10,000 steps, so the target can be consistently wrong. Freezing trades bias for a stable, measurable error.
