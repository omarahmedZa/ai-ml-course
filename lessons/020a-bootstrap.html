Value functions, one symbol at a time · Lab 1

V(s) = r + γV(s′) — bootstrapping

You can price a state from one reward and one estimate of the next state, without ever finishing an episode.

Where this sits

V(s) = E[ r + γ V(s′) ]

Topic 20 · the backup is lit; the expectation wrapped around it stays dim

V(s) is the expected return from state s: one number standing in for every future you might live through. The backup builds it from two pieces you already have — today's reward, and the value of wherever you land next.

Bootstrapping means using a guess to improve a guess. V(s′) is not known either. It is the current estimate, and it is good enough to move V(s) closer to the truth.

Value now, value next

Read the strip as: what I collect now, plus what the rest of the trip is worth, discounted once. The endless sum from topic 19 is never written out. The tail is folded into a single table lookup, which is what makes the arithmetic finite.

The expectation E[·] is there because the next state can be random; with one known successor the average drops away and the bracket on its own is the backup.

A chain of three states

Take γ = 0.9 and a reward of 1 at each step. The last state is worth 2. Then V(s′) = 1 + 0.9 × 2 = 2.8, and V(s) = 1 + 0.9 × 2.8 = 3.52. Each box inherits its neighbour's number, discounted, plus its own reward.

The recursion is the algorithm

You do not need a finished episode. One transition and one current estimate are enough to improve V(s). Sweep every state, again and again, and the numbers settle; that loop is policy evaluation. The same backup run on samples instead of a known table is TD learning.

The trap

Most common wrong mental model

"Bootstrapping is circular, so it cannot be computed." The equation does refer to itself one step later, and that is the point: it is a system of simultaneous equations, not a dead end.

Correction: each sweep multiplies the error by γ, so from any starting guess the values converge. γ < 1 is what guarantees the correction shrinks rather than amplifies.

The tell: initialise every V at 0 and run the sweep. The numbers climb to 3.52 and stop moving. A genuinely circular definition would never settle, because nothing would break the loop.

Retrieval check

  1. r = 2, γ = 0.5, V(s′) = 4. What is V(s)?
    Answer

    2 + 0.5 × 4 = 4.0. Half of the next state's value plus the reward — the discount is applied once, not twice.

  2. Why can V(s) be updated before the episode ends?
    Answer

    Because the unobserved tail is carried by V(s′), which is already in the table. The backup never asks what happens after s′; it asks what s′ is currently worth.
