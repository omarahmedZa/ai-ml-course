Unit 2 · Neural network mechanics · Topic 8 of 35

The neuron: weighted sum plus one bend

You can prove that stacked linear layers collapse into one, so a nonlinearity is mandatory.

Why this matters

If you cannot say why the ReLU is there, you cannot debug a network that refuses to learn. The entire expressive power of deep learning lives in that one non-linear function between layers.

The one core idea

A neuron computes a = φ(w·x + b). The dot product decides what it looks for; φ is the only thing that stops the whole network from being one matrix.

How it actually works

  • w·x + b — a linear score, exactly topic 1. b shifts the threshold, so the neuron can fire at x = 0 or not.
  • φ — the activation, applied elementwise. Without it, a neuron is logistic regression.
  • Why φ is mandatory: take two layers, h = W₁x + b₁ then y = W₂h + b₂. Substitute: y = (W₂W₁)x + (W₂b₁ + b₂). That is a single linear layer with weights W₂W₁. Any depth collapses.
  • Common activations: ReLU max(0, z) — cheap, no saturation for positive inputs; sigmoid — probabilities, saturates; tanh — zero-centred, still saturates; GELU — smooth ReLU, standard in transformers.
2 → 2 → 1 network: (2·2 + 2) + (2·1 + 1) = 9 parameters

Worked example

1. The collapse, with numbers

W₁ = [[1, 2], [3, 4]], b₁ = 0, x = [1, 1] → h = [3, 7]. Then W₂ = [1, −1], b₂ = 0 → y = 3 − 7 = −4.

Now collapse: W₂W₁ = [1·1 + (−1)·3, 1·2 + (−1)·4] = [−2, −2], and [−2, −2]·[1, 1] = −4. Identical. Two layers, one matrix, zero extra power.

2. The same network with a ReLU

h = ReLU([3, 7]) = [3, 7] — no change here, because both were positive. Try x = [1, −1]: h = [1−2, 3−4] = [−1, −1] → ReLU → [0, 0]. Output 0, whereas the collapsed linear model would give [−2,−2]·[1,−1] = 0. Pick x = [2, −1] instead: linear gives −2; with ReLU, h = [0, 2] → y = −2. Coincidence again — but now change W₂ to [1, 1]: linear gives 0, ReLU gives +2. The bend has created a behaviour no single matrix can produce.

The trap

Most common wrong mental model

"A neuron is a simplified brain cell." It is a dot product and a clamp. The metaphor invites the wrong intuitions (that neurons "detect concepts") and none of the maths.

Second trap: forgetting the bias. Removing b forces every neuron's boundary through the origin; on data not centred there, the network needs absurd weights to compensate. Always initialise and train biases.

Retrieval check

  1. Why does removing all activation functions make a 50-layer network no stronger than logistic regression?
    Answer

    A product of matrices is a matrix. W₅₀…W₁x equals Wx for some W, so depth adds parameters but not expressiveness.

  2. Count the parameters in a 3 → 4 → 2 network, biases included.
    Answer

    Layer 1: 3·4 + 4 = 16. Layer 2: 4·2 + 2 = 10. Total 26.

  3. A ReLU unit outputs 0 for every input in your batch. What happened, and what are two fixes?
    Answer

    The unit is "dead": its pre-activation is negative everywhere, so its gradient is 0 and it can never recover. Fixes: lower the learning rate, or use LeakyReLU/GELU so negative inputs keep a gradient.

Build it in Colab

Runnable, NumPy-only, no setup: open the notebook in Colab · local copy. The cell prints numbers, not pictures — change one value and rerun to see what breaks.

import numpy as np
W1 = np.array([[1., 2.], [3., 4.]])
x = np.array([1., -1.])
for W2 in (np.array([[1., -1.]]), np.array([[1., 1.]])):
    deep = W2 @ (W1 @ x)
    collapsed = (W2 @ W1) @ x
    relu = W2 @ np.maximum(0, W1 @ x)
