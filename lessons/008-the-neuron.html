The neuron: weighted sum plus one bend

You can prove that stacked linear layers collapse into one, so a nonlinearity is mandatory.

Neural NetworksDeep Learning

Why this matters— the neuron

A neuron is the smallest trainable unit in every network here: one weighted sum, one bias, one bend. Embeddings, attention heads and output layers are stacks of it.

Two failures make it worth an hour. In an exam, "a 50-layer network with no activations — how much more can it represent than a single linear layer?" has a one-line answer: nothing, because a product of matrices is a matrix. In a project, the same mistake shows up as a loss that drops to the level of logistic regression and sits there, because the ReLU was deleted during a cleanup. Neither symptom is visible unless you can point at the missing part.

The one core idea— the neuron

A neuron is a straight-line score with a gate on its output. The score says which side of a boundary the input falls on, and how far; the gate decides how much of it survives into the next layer. Training changes only the weights — the gate is fixed.

In one line: score first, then bend. With w = [2, −3] and b = 1, the input [1, −1] scores 2 + 3 + 1 = 6 and ReLU returns 6; the input [−2, 1] scores −4 − 3 + 1 = −6 and ReLU returns 0.

a = max(0, w·x + b)

Score first, then bend: a dot product followed by a fixed clamp.

How it actually works— the neuron

Four objects in a fixed order — a weighted sum, a bias, a bend, a count — across seven steps, each supplying what the last left open.

Step 1 — Score the input with a weighted sum

A neuron holds a weight vector w and a bias b, and for one input x it computes z = w·x + b. That z is the pre-activation: the raw score before any bend, and exactly topic 1's dot product. For w = [2, −3, 0.5] and x = [1, 4, 2] the score is 2(1) − 3(4) + 0.5(2) = 2 − 12 + 1 = −9. The score fixes what the neuron looks for, but nothing yet says what −9 should mean.

Step 2 — Use the bias to set when it fires

The bias is one number added after the dot product. It shifts the score without changing what the neuron looks for, which moves the boundary w·x + b = 0 away from the origin. With b = 0 and w = [2, −3], inputs on 2x₁ − 3x₂ = 0 score zero; with b = 1 those same inputs score 1 and switch on. Scores still run from −∞ to ∞, and a classifier needs a bounded answer.

Step 3 — Bend the score with an activation

The activation φ is a fixed function applied to z one number at a time. The default is ReLU, φ(z) = max(0, z): negative scores become 0, positive scores pass through unchanged, so z = [−1, 0, 3, 7] becomes a = [0, 0, 3, 7]. Being elementwise it mixes nothing between units. One bend is not obviously worth its cost — so stack two layers and watch what it buys.

Step 4 — See what removing the bend would cost

Two stacked layers give h = W₁x + b₁, then y = W₂h + b₂. Substituting the first into the second: y = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂) — one linear layer with weights W₂W₁ and bias W₂b₁ + b₂. Stack fifty and you still hold one matrix, plus parameters that buy nothing. The bend is therefore mandatory; the open question is which one.

Step 5 — Pick a bend and pay its price

ReLU is cheap and never saturates on the positive side — its slope stays 1 — but it is flat below zero, so a unit stuck there learns nothing. Sigmoid, 1/(1 + e⁻ᶻ), squashes into (0, 1) and can be read as a probability, at the cost of saturation: at z = 10 the output is 0.99995. Tanh is a zero-centred sigmoid on (−1, 1); GELU is a smooth ReLU and the default inside transformers.

Step 6 — Count the parameters before you train

Each neuron owns one weight per input plus a single bias, so a layer with n_in inputs and n_out neurons has n_in·n_out + n_out parameters. A 2 → 2 → 1 network costs (2·2 + 2) + (2·1 + 1) = 6 + 3 = 9. The count gives the memory and data budget before the first run, and a mismatch with sum(p.numel()) finds a layer wired to the wrong input — once you can write the layer.

Step 7 — Write the layer as one row per neuron

Stack n_out neurons that read the same input and their weight vectors become the rows of a matrix. The layer computes Wx + b with W of shape n_out × n_in and b of length n_out, and each row is one neuron's question; the bend then runs entry by entry on the resulting vector. That is what lets a GPU compute a thousand neurons at once, and it is the bridge to shapes in topic 9.

2 → 2 → 1 network: (2·2 + 2) + (2·1 + 1) = 9 parameters

Worked example— the neuron

1. One neuron, three inputs

w = [2, −3, 0.5], b = 1. Do each multiplication explicitly; sign errors survive when you skip them.

[1, 4, 2]2(1) = 2−3(4) = −120.5(2) = 1−9 → 0

What to notice. The neuron is not a yes/no gate. It outputs 0, 7 and 1, so the size carries confidence and the sign decides the side. The middle row changed only the second feature, from 4 to −1, and the score moved by 16 — a weight of −3 reacts to a negative feature as strongly as to a positive one. The third row is the bias alone.

2. Two layers collapsing into one

W₁ = [[1, 2], [3, 4]], b₁ = 0, x = [1, 1], then W₂ = [1, −1], b₂ = 0. Compute the deep version and the collapsed version side by side.

What to notice. The two routes agree to the digit, and that is not luck: one is an algebraic rearrangement of the other. The second layer never sees anything the first did not already express as a linear function of x, so its weights only change the coefficient vector. Depth without a bend is an expensive way to write one matrix.

3. The same weights with a ReLU

Keep W₁ and swap W₂ to [1, 1], so the collapsed linear map is W₂W₁ = [4, 6]. Compare the linear prediction [4, 6]·x with the ReLU network [1, 1]·ReLU(W₁x) on three inputs.

What to notice. The ReLU network agrees with the straight line on two of the three inputs and breaks from it on the middle one. That disagreement is the whole gain: the function is now piecewise. No single matrix produces 10, −2 and 2 at those inputs unless it is [4, 6], and [4, 6] gets the middle row wrong.

3. Check yourself

On paper first.

  1. w = [1, −2], x = [3, 1], b = 0.5. Score it, then apply ReLU.
    Answer

    z = 3 − 2 + 0.5 = 1.5; positive, so ReLU passes it through unchanged: a = 1.5.

  2. A layer reads 4 inputs and writes 3 outputs. How many parameters, and what shape is W?
    Answer

    4·3 + 3 = 15: twelve weights and three biases. W is 3 × 4, one row per neuron, and b has length 3.

  3. No biases: W₁ is 2 × 3 and W₂ is 1 × 2. What does the stack equal?
    Answer

    One linear layer with W = W₂W₁, shape 1 × 3 — no bend, so the second layer added nothing.

The trap— the neuron

Most common wrong mental model

"A neuron is a simplified brain cell." It feels right because the diagram — inputs, a cell body, one output — is the textbook picture, and the word is identical.

Correction: a neuron is max(0, w·x + b) and nothing else. There is no memory, no timing, no spiking. The inputs are a dot product, the "firing" is a clamp at zero, and training touches only weights and bias. Any biology intuition must be re-derived from that line or discarded.

The tell: you can describe what a unit does but cannot write its four numbers — weights, input, bias, output — on one line. The second tell: a unit that outputs 0 for every example has all-negative pre-activations and a gradient of zero forever. Check z first.

Retrieval check— the neuron

  1. Why does removing all activation functions make a 50-layer network no stronger than logistic regression?
    Answer

    A product of matrices is a matrix. W₅₀…W₁x equals Wx for some W, so depth adds parameters but not expressiveness.

  2. Count the parameters in a 3 → 4 → 2 network, biases included.
    Answer

    Layer 1: 3·4 + 4 = 16. Layer 2: 4·2 + 2 = 10. Total 26.

  3. A ReLU unit outputs 0 for every input in your batch. What happened, and what are two fixes?
    Answer

    The unit is "dead": its pre-activation is negative everywhere, so its gradient is 0 and it can never recover. Fixes: lower the learning rate, or use LeakyReLU/GELU so negative inputs keep a gradient.
