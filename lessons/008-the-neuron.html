The neuron: weighted sum plus one bend

You can prove that stacked linear layers collapse into one, so a nonlinearity is mandatory.

Why this matters

A neuron is the smallest trainable unit in every network here: one weighted sum, one bias, one bend. Embeddings, attention heads and output layers are stacks of it.

Two failures make it worth an hour. In an exam, "a 50-layer network with no activations — how much more can it represent than a single linear layer?" has a one-line answer: nothing, because a product of matrices is a matrix. In a project, the same mistake shows up as a loss that drops to the level of logistic regression and sits there, because the ReLU was deleted during a cleanup. Neither symptom is visible unless you can point at the missing part.

The one core idea

A neuron is a straight-line score with a gate on its output. The score says which side of a boundary the input falls on, and how far; the gate decides how much of that score survives into the next layer. Training changes only the score's weights — the gate is fixed and never learned.

In one line: score first, then bend. With w = [2, −3] and b = 1, the input [1, −1] scores 2 + 3 + 1 = 6 and ReLU returns 6; the input [−2, 1] scores −4 − 3 + 1 = −6 and ReLU returns 0.

How it actually works

Part 1 — The weighted sum is the score

A neuron holds a weight vector w and a bias b, and for one input x it computes z = w·x + b. That z is the pre-activation: the raw score before any bend, and exactly topic 1's dot product. For a 3-input neuron with w = [2, −3, 0.5] and x = [1, 4, 2], the score is 2 − 12 + 1 = −9. Why this part exists: it fixes what the neuron looks for before anything else touches the number, so a wrong sign here is a wrong model, not a rounding detail.

Part 2 — The bias decides when it fires

The bias is one number added after the dot product. It shifts the score without changing what the neuron looks for, which moves the boundary w·x + b = 0 away from the origin. With b = 0 and w = [2, −3], inputs on 2x₁ − 3x₂ = 0 score zero; with b = 1 those same inputs score 1 and switch on. Why this part exists: without it every boundary passes through the origin, so data centred elsewhere forces huge weights just to push the fence sideways.

Part 3 — Then bend the score

The activation φ is a fixed function applied to z, one number at a time. The default is ReLU, φ(z) = max(0, z): negative scores become 0, positive scores pass through unchanged. Being elementwise, it bends a layer's scores independently, with no mixing, so z = [−1, 0, 3, 7] becomes a = [0, 0, 3, 7]. Why this part exists: the bend is the only source of curvature in the network, and without curvature no amount of depth produces a new function.

Part 4 — Without the bend, depth is a lie

Take two layers, h = W₁x + b₁ then y = W₂h + b₂, and substitute the first into the second: y = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂). That is one linear layer with weights W₂W₁ and bias W₂b₁ + b₂. Stack fifty and you still have one matrix, plus parameters that buy nothing. Why this part exists: it is the proof that a nonlinearity is mandatory, and it is the first thing an examiner asks you to reproduce on paper.

Part 5 — Each activation trades something away

ReLU is cheap and never saturates on the positive side — its slope stays 1 — but it is flat below zero, so a unit stuck there learns nothing. Sigmoid, 1/(1 + e⁻ᶻ), squashes into (0, 1) and can be read as a probability, at the cost of saturation: at z = 10 the output is 0.99995. Tanh is a zero-centred sigmoid on (−1, 1); GELU is a smooth ReLU and is the default inside transformers. Why this part exists: the choice sets the size of the gradient flowing back, so it decides whether learning is fast, glacial, or dead.

Part 6 — Count the parameters before you train

Each neuron owns one weight per input plus a single bias, so a layer with n_in inputs and n_out neurons has n_in·n_out + n_out parameters. A 2 → 2 → 1 network costs (2·2 + 2) + (2·1 + 1) = 6 + 3 = 9. Why this part exists: it gives the memory and data budget before the first run, and a mismatch with sum(p.numel()) is the fastest way to find a layer wired to the wrong input.

Part 7 — A layer is one row per neuron

Stack n_out neurons that read the same input and you have a matrix whose rows are their weight vectors. The layer computes Wx + b with W of shape n_out × n_in and b of length n_out; each row is one neuron's question. The bend runs entry by entry, now on a vector. Why this part exists: the matrix view lets a GPU compute a thousand neurons at once, and it is the bridge to the next topic, where shapes take over.

2 → 2 → 1 network: (2·2 + 2) + (2·1 + 1) = 9 parameters

Worked example

1. One neuron, three inputs

w = [2, −3, 0.5], b = 1. Do each multiplication explicitly; sign errors survive when you skip them.

What to notice. The neuron is not a yes/no gate. It outputs 0, 7 and 1, so the size carries confidence and the sign decides the side. The middle row changed only the second feature, from 4 to −1, and the score moved by 16 — a weight of −3 reacts to a negative feature as strongly as to a positive one. The third row is the bias alone.

2. Two layers collapsing into one

W₁ = [[1, 2], [3, 4]], b₁ = 0, x = [1, 1], then W₂ = [1, −1], b₂ = 0. Compute the deep version and the collapsed version side by side.

What to notice. The two routes agree to the digit, and that is not luck: one is an algebraic rearrangement of the other. The second layer never sees anything the first did not already express as a linear function of x, so its weights only change the coefficient vector. Depth without a bend is an expensive way to write one matrix.

3. The same weights with a ReLU

Keep W₁ and swap W₂ to [1, 1], so the collapsed linear map is W₂W₁ = [4, 6]. Compare the linear prediction [4, 6]·x with the ReLU network [1, 1]·ReLU(W₁x) on three inputs.

What to notice. The ReLU network agrees with the straight line on two of the three inputs and breaks from it on the middle one. That disagreement is the whole gain: the function is now piecewise, flat on one region and sloped on another. No single matrix can produce 10, −2 and 2 at those inputs unless it is exactly [4, 6], and [4, 6] gets the middle row wrong.

The trap

Most common wrong mental model

"A neuron is a simplified brain cell." It feels right because the diagram — inputs, a cell body, one output — is the textbook picture, and the word is identical.

Correction: a neuron is max(0, w·x + b) and nothing else. There is no memory, no timing, no spiking. The inputs are a dot product, the "firing" is a clamp at zero, and training touches only weights and bias. Any biology intuition — that it detects a concept — has to be re-derived from that line or discarded.

The tell: you can describe what a unit does but cannot write its four numbers — weights, input, bias, output — on one line. Debugging gives the second tell: a unit that outputs 0 for every example has all-negative pre-activations and a gradient of exactly zero forever. Check z first.

Retrieval check

  1. Why does removing all activation functions make a 50-layer network no stronger than logistic regression?
    Answer

    A product of matrices is a matrix. W₅₀…W₁x equals Wx for some W, so depth adds parameters but not expressiveness.

  2. Count the parameters in a 3 → 4 → 2 network, biases included.
    Answer

    Layer 1: 3·4 + 4 = 16. Layer 2: 4·2 + 2 = 10. Total 26.

  3. A ReLU unit outputs 0 for every input in your batch. What happened, and what are two fixes?
    Answer

    The unit is "dead": its pre-activation is negative everywhere, so its gradient is 0 and it can never recover. Fixes: lower the learning rate, or use LeakyReLU/GELU so negative inputs keep a gradient.

Build it in Colab

Runnable, NumPy-only, no setup: open the notebook in Colab · local copy. The cell prints numbers, not pictures — change one value and rerun to see what breaks.

import numpy as np
W1 = np.array([[1., 2.], [3., 4.]])
x = np.array([1., -1.])
for W2 in (np.array([[1., -1.]]), np.array([[1., 1.]])):
    deep = W2 @ (W1 @ x)
    collapsed = (W2 @ W1) @ x
    relu = W2 @ np.maximum(0, W1 @ x)

Extra practice
