Part of Topic 27 · The Transformer block — where the residual connection is introduced

The block, one line at a time · Lab 1

x + MHA(LN(x)) — the residual path

You can read the line left to right, say what the addition preserves, and explain why the identity path keeps gradients alive in a deep stack.

Where this sits

x′ = x + MHA( LN(x) )

Lab 1 · the addition is lit; the prime marks the block's output

The block has two sub-layers, and each one is wrapped the same way. This lab reads the attention half. The feed-forward half repeats the shape with a different branch, so once this line is clear, the block is clear.

Three symbols in one line

x is one token's vector: 512 numbers, say. LN is LayerNorm, which rescales those numbers to mean 0 and spread 1 and then applies a learned scale and shift. MHA is multi-head attention, the only part that moves information between tokens. The result is added back to x.

A highway beside the branch

The branch can shrink its output to almost nothing, or make it large. The copy of x does neither: it bypasses LN and attention entirely and arrives unchanged. So the block's output is always the input plus a change. Nothing is overwritten, and the original vector stays reachable at every depth.

Why gradients survive

Training multiplies local slopes backwards through the stack. Through the branch alone, that is a product of numbers below 1, which shrinks fast: 0.9 taken to the 96th power is 0.00004. Through the addition, the slope of x + f(x) is 1 + f′(x). Each factor carries that constant 1, so the product cannot decay geometrically.

Why LayerNorm sits inside the branch

Pre-LN normalises the input to each sub-layer, so the highway stays a clean chain of additions. Post-LN normalises after the addition, which puts a division on the highway; very deep post-LN models then need a long learning-rate warmup to stay stable. Modern blocks use pre-LN for exactly this reason.

What the addition costs

No new parameters. It stores one extra d-wide vector per token per sub-layer for the backward pass and performs d additions. Next to the two matrix multiplies inside the branch, that is close to free.

Faded example

Take x = [2, 4, 6, 8]. LayerNorm subtracts the mean 5 and divides by the spread 2.236, giving [−1.34, −0.45, 0.45, 1.34]. Suppose the branch returns [0.5, −0.5, 0.5, −0.5].

Check the last two rows

Zero branch: x′ = [2, 4, 6, 8], the input unchanged. Unit branch: x′ = [3, 5, 7, 9]. Notice that the LayerNorm output never appears in x′ directly — it only shaped what the branch produced.

The trap

Most common wrong mental model

"The residual keeps the input, so the block does nothing." The addition guarantees the input is available, not that the branch is ignored. A trained branch writes real changes into the stream; that is how the model learns anything at all.

Correction: the residual is a guarantee about the path, not a statement about the size of the change. Zero the branch's output weights and the block is exactly the identity — a useful test, not normal behaviour.

The tell: measure the norm of the branch output in a trained model. It is not near zero. If someone claims "the residual means extra layers are free", ask them for the parameter count and the attention cost of those layers.

Retrieval check

  1. x = [10, 10] and the branch returns [−2, 2]. What is x′?
    Answer

    [8, 12]. The addition is element by element, so each number meets its own change.

  2. Why does a constant 1 in the derivative matter more than its size?
    Answer

    Because the backward pass multiplies one factor per block. A product of numbers all below 1 collapses; a product where every factor contains 1 does not, however small the branch term is.
