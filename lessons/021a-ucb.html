UCB — the optimism bonus

You can compute a UCB score for three arms and explain why the least-tried one wins.

Where this sits

a = argmaxa Q(a) + c √( ln t / N(a) )

Topic 21 · the score is lit; the choice it drives stays dim

Every Q is an average of a handful of samples, so it carries an error bar. Greedy selection ignores the bar and keeps whichever action happened to start well. That action's estimate never gets the data that would correct it.

UCB fixes this without rolling dice. It adds the error bar to the score and takes the largest total, so doubt itself becomes a reason to act.

The bonus is a width

√(ln t / N(a)) is roughly the width of the interval around Q(a): few pulls make it wide, many pulls make it narrow. c sets how many widths of doubt you add. c = 2 is a common default, and c = 0 collapses the rule back to greedy. Total pulls can keep climbing while every interval still narrows.

Three arms, one decision

At t = 100 pulls, ln t ≈ 4.61 and c = 2. Arm A has the best average and almost no bonus. Arm C has the worst average and the widest bonus — and it wins the round.

A6.050+0.616.61
B5.010+1.366.36
C4.02+3.037.04

What happens over time

t counts every pull, so ln t grows slowly and identically for all arms. N(a) grows only for the arm you actually pull. An untried arm keeps its wide bonus; a well-sampled arm must win on Q alone. Certainty is penalised, ignorance is subsidised — and the subsidy shrinks as it is spent.

The bonus never disappears entirely, so no arm is ever abandoned for good. That is what stops the rule freezing on an early winner.

Faded example

Same round: t = 100, c = 2. Arm D has Q = 5.5 and N = 25. Fill the bonus and the total with the last step removed.

Check arm D

4.61 / 25 = 0.184; its square root is 0.429; times c = 2 gives 0.86. The score is 5.5 + 0.86 = 6.36, level with B. D reached that total from more pulls and a better average, so the two effects cancelled exactly here — a coincidence, not a rule.

The trap

Most common wrong mental model

"The bonus is a hack that forces exploration." It is a confidence bound with a stated width, computed from counts. No randomness is injected and nothing is tuned per task beyond c.

Correction: read the score as an optimistic guess of the arm's true mean. You are not adding noise; you are adding the distance between the estimate and the best value still consistent with the data.

The tell: set c = 0 and every trace of exploration vanishes — the rule becomes argmax Q. If exploration survives c = 0, it came from somewhere else, such as ε-greedy noise or arbitrary tie-breaking.

Retrieval check

  1. Why does the bonus shrink as N grows?
    Answer

    Because N sits in the denominator: more samples means a narrower interval around the average, so less doubt needs to be added. The estimate has earned the right to be taken at face value.

  2. An arm has N = 1 at t = 100, with c = 2. Roughly how large is its bonus?
    Answer

    2 × √4.61 ≈ 4.3. A single pull leaves enormous doubt, so the bonus alone can lift an arm above a well-sampled one with a much better average.
