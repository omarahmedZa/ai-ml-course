Function approximation: why tables die

You can explain why tabular RL fails at scale, and why approximation removes the convergence guarantee.

Why this matters

Every deep RL result — Atari, Go, robot locomotion, RLHF — exists because someone replaced a table with a neural network. The price is the guarantee, and the exam will ask what was lost.

The one core idea

Tabular RL stores one number per state. When states are images, that table cannot exist — so you approximate Q(s,a) ≈ Q_θ(s,a), trading exactness for generalisation, and losing the convergence proof with it.

How it actually works

  • Table size: |S| × |A|. A 25-cell grid is trivial. An Atari frame is 210×160 pixels with 256 values each — more states than atoms in the observable universe.
  • Approximation generalises: updating one state changes predictions for nearby states. That is the point — and the danger.
  • The deadly triad (Sutton & Barto): function approximation + bootstrapping + off-policy data can diverge. Any two are fine; all three together are not.
  • Why: the target r + γ max Q_θ(s′) depends on the same weights you are updating. You are chasing a target that moves when you move — and approximation makes the error affect states you never visited.
  • Supervised assumptions break: samples are correlated in time (not i.i.d.), the distribution shifts as the policy changes, and the label is a guess.
Q(s,a) → Q_θ(s,a) loss = ( r + γ max_{a′} Q_θ(s′,a′) − Q_θ(s,a) )²

2. What generalisation buys — and costs

Two grid cells look identical to the network (same input features). Update one, and the other's value changes too. Usually that is helpful: experience transfers. But if the two cells need opposite values, the network averages them and neither is correct. That is catastrophic interference, and it is invisible in a table.

The trap

Most common wrong mental model

"A neural network is just a big table with better memory." It is a smooth function over all inputs. That smoothness is an assumption — and if the true value function is discontinuous, approximation will average across the discontinuity and never represent it.

Second trap: assuming RL convergence proofs survive the swap. Tabular Q-learning converges to Q*; with approximation and off-policy bootstrapping, it can oscillate or diverge. DQN's fixes (topic 24) are engineering, not a proof.

Retrieval check

  1. Why is a table impossible for a camera-based robot?
    Answer

    The state is a high-dimensional image, so |S| is astronomically large. No table of that size can be stored, and most states would never be visited anyway.

  2. Name the three ingredients of the deadly triad.
    Answer

    Function approximation, bootstrapping (using estimated values as targets), and off-policy training. Any two are stable; all three can diverge.

  3. Why does approximation break the i.i.d. assumption that supervised learning relies on?
    Answer

    Transitions arrive in temporal order from the current policy, so consecutive samples are highly correlated and the data distribution shifts as the policy improves.
