Backpropagation

You can apply the chain rule to a small graph and say what each gradient means.

Why this matters

Every "the model won't learn" bug is a gradient bug: wrong sign, vanished, exploded, or detached. Backprop is the one mechanism you must be able to inspect rather than trust.

The one core idea

Backprop is the chain rule applied right-to-left over the computation graph: each node passes its local derivative back to its inputs, multiplied by the derivative flowing in from the loss.

How it actually works

  • Graph: every operation (add, multiply, ReLU, matmul) is a node. The forward pass stores the values it needs.
  • Upstream gradient ∂L/∂out arrives at a node. The node multiplies it by its local derivative ∂out/∂in and passes the product down.
  • Fan-out adds: if a value feeds two paths, the gradients from both are summed. This is why "gradient accumulation" works.
  • One sweep suffices: reverse-mode automatic differentiation costs roughly one extra forward pass, regardless of how many parameters there are. Numerical gradients would cost one pass per parameter.
∂L/∂w = ∂L/∂out · ∂out/∂z · ∂z/∂w

Worked example

1. One linear unit, by hand

z = wx + b, L = (z − y)², with x = 2, w = 3, b = 1, y = 10.

With η = 0.1: w = 3 − 0.1(−12) = 4.2, b = 1 − 0.1(−6) = 1.6. Feed forward: 4.2(2) + 1.6 = 10, loss 0. One step, exact — because this loss is quadratic and the step was chosen well.

2. Reading a real graph

For L = (a·b + c)² with a=2, b=3, c=1: u = ab + c = 7, L = 49. Then ∂L/∂u = 2u = 14, so ∂L/∂a = 14·b = 42, ∂L/∂b = 14·a = 28, ∂L/∂c = 14. Three gradients from one backward sweep — that is the entire trick.

The trap

Most common wrong mental model

"Backprop is a special algorithm for neural networks." It is reverse-mode autodiff, and it works on any differentiable graph — physics simulations, rendering, control. Networks are just the most profitable place to point it.

Second trap: reading a gradient as "how important this parameter is". It is a local slope at the current parameters. The same weight can have a huge gradient at initialisation and a tiny one a step later.

Retrieval check

  1. L = (3w)². What is dL/dw at w = 2?
    Answer

    L = 9w², so dL/dw = 18w = 36. Via the chain rule: 2(3w)·3 = 18w. Same answer; the chain rule is not optional bookkeeping, it is the derivative.

  2. A value feeds two branches of the graph. How do the two gradients combine?
    Answer

    They add. Total derivative = sum of contributions from every path. This is exactly why accumulating gradients across micro-batches is mathematically valid.

  3. Why is backprop cheaper than finite differences for 1M parameters?
    Answer

    Finite differences need two forward passes per parameter — about 2M passes. Backprop gets every gradient in one backward pass, roughly the cost of one forward pass.
