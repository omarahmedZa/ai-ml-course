Eigenvalues, eigenvectors & SVD

You can find the directions a matrix only stretches, read off the stretch factors, and use the SVD to compress a matrix or summarise what it does.

FoundationsLinear Algebra

Why this matters— directions that survive a matrix

Most numbers in a trained model live in one big matrix, and much of that matrix is redundant. A 1,000 × 1,000 weight matrix holds a million entries, but often ten directions explain almost all of it. Eigenvalues and the singular value decomposition find those directions. They are how PCA turns 784 pixels per digit into 30 numbers.

The failure it prevents. A model trains, the loss looks fine, then a matrix inverse explodes or an approximation destroys accuracy. Both are visible in the singular values before anything breaks. An exam question asking for eigenvalues tests whether you can read the algebra as geometry.

The one core idea— directions that survive a matrix

Multiplying a vector by a matrix usually turns it and changes its length. A few special vectors only change length. Those are the eigenvectors; the factor by which their length changes is the eigenvalue.

Write the matrix as A, the vector as v, the stretch as λ(lambda) (lambda). The whole idea is one equation: A v = λ v. The left side applies the matrix; the right side only scales the same vector.

The SVD extends this to every matrix. It says any matrix is three moves: rotate, stretch along perpendicular axes, rotate again. The stretch amounts are the singular values σ₁ ≥ σ₂ ≥ … ≥ 0(sigma) (sigma), always real and never negative.

A v = λ v  ·  A = U Σ Vᵀ

Eigenvectors are directions that survive; singular values are the sizes of the stretch.

How it actually works— directions that survive a matrix

Part 1 — Find an eigenvector by testing directions

Take A = [[3,1],[1,3]] and try v = (1,1). The first row gives 3(1) + 1(1) = 4; the second gives 1(1) + 3(1) = 4. So A v = (4,4) = 4v: no turn, length multiplied by 4. Try v = (1,−1): the rows give 2 and −2, so A v = 2v. Two directions, two stretches, and together they explain everything the matrix does.

Why this matters: each eigenvector is a coordinate the matrix treats independently, so powers and inverses simplify.

Part 2 — Solve for the eigenvalues

Guessing works only for friendly matrices. Since A v = λ v means (A − λI) v = 0, with I the identity, a non-zero v exists only when the determinant of A − λI is zero. Here that is (3 − λ)² − 1 = 0, so 3 − λ = ±1 and λ = 4 or λ = 2. The polynomial has one root per dimension.

Why this matters: symmetric matrices always give real roots and perpendicular eigenvectors, which makes covariance matrices safe to decompose.

Part 3 — Factor any matrix with the SVD

Rectangular matrices have no square eigenvectors. The SVD avoids the problem: A = U Σ Vᵀ(sigma). U holds output directions, V input directions, and Σ is diagonal with σ₁,σ₂,… sorted largest first. For a 500 × 20 matrix, U is 500 × 20 and Σ, V are 20 × 20. The singular values are the square roots of the eigenvalues of AᵀA.

Why this matters: truncating the factorisation gives the best possible low-rank approximation — the Eckart–Young theorem. Keeping the top k terms is not a heuristic; no rank-k matrix is closer.

Part 4 — Truncate to compress

The SVD writes A as a sum of rank-one pieces: A = σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + …. Each piece is one direction pair weighted by its singular value. If σ₃ is tiny next to σ₁, that piece contributes little and can be dropped. Storing the top k pieces of a 1,000 × 1,000 matrix costs k(2,000 + 1) numbers; at k = 10 that is 20,010 instead of 1,000,000, a 98% saving.

Why this matters: the error is fixed by the singular values you discard, so compression becomes a budget decision.

Worked example— directions that survive a matrix

1. Two directions, by hand

Start from A = [[3,1],[1,3]]. For λ = 4, (A − 4I) v = 0 becomes [[−1,1],[1,−1]] v = 0, so v₁ = v₂; pick v = (1,1). For λ = 2, [[1,1],[1,1]] v = 0, so v₂ = −v₁; pick v = (1,−1). Normalise by dividing by √2 = 1.414(square root): u₁ = (0.707,0.707), u₂ = (0.707,−0.707), perpendicular as promised.

DirectionA vλ vStretch
(1,1)(4, 4)(4, 4)4.0
(1,−1)(2, −2)(2, −2)2.0
(1,0)(3, 1)—3.16

Read the last row. (1,0) comes out as (3,1), length √10 = 3.16, and it also turned. Only the two special directions keep their orientation.

2. Rebuild the matrix from its pieces

The reconstruction is A = λ₁u₁u₁ᵀ + λ₂u₂u₂ᵀ. The first outer product has every entry 0.707 × 0.707 = 0.5, so 4 × that = [[2,2],[2,2]]. The second has alternating signs: u₂u₂ᵀ = [[0.5,−0.5],[−0.5,0.5]], so 2 × that = [[1,−1],[−1,1]]. Add them and you get [[3,1],[1,3]] back, exactly.

Now drop the small piece. Keeping only σ₁ = 4 gives [[2,2],[2,2]]. The leftover [[1,−1],[−1,1]] has size √4 = 2, while the original had size √20 = 4.47, so the relative error is 2 / 4.47 = 44.7%. That is bad here because 2 is half of 4; with singular values 40 and 2, the same move would cost 5%.

The trap— directions that survive a matrix

Most common wrong mental model

"Eigenvalues and singular values are the same thing." They coincide only for symmetric matrices with non-negative eigenvalues. Eigenvalues describe what a matrix does to its own special directions; singular values describe how much it stretches any direction at all.

Take A = [[0,2],[0,0]]. Its characteristic polynomial is λ², so both eigenvalues are 0 — read carelessly, the matrix does nothing. But A sends (0,1) to (2,0): it doubles a vector. Its singular values are 2 and 0.

Correction: eigenvalues can be negative or complex and measure stretch only along eigenvectors; singular values are always real, non-negative, and bound the stretch of the whole unit sphere.

The tell: a covariance matrix with a negative eigenvalue is not a valid covariance matrix. All-zero eigenvalues beside a non-zero output mean you are reading the wrong decomposition. Both are caught by checking A v against λ v on one vector.

Retrieval check— directions that survive a matrix

  1. For A = [[2,0],[0,5]], name the eigenvectors and eigenvalues without solving anything.
    Answer

    (1,0) with λ = 2, and (0,1) with λ = 5. A diagonal matrix already acts independently on each axis, so the axes are the eigenvectors and the diagonal entries are the stretches.

  2. You keep the top 10 of 200 singular values and all discarded ones are below 0.01. Is the approximation safe?
    Answer

    Almost certainly. The Frobenius error is at most √(190 × 0.0001) = 0.138. Compare that with the largest singular value, not with zero.

  3. Why can a 300 × 4 matrix have at most four non-zero singular values?
    Answer

    Because there is one singular value per column of Σ, and rank cannot exceed the smaller dimension. The matrix maps 4-dimensional space into 300 dimensions, so its image is at most 4-dimensional.

Build it in Colab— directions that survive a matrix

Runnable, NumPy-only: open the notebook in Colab · local copy. It checks A v = λ v numerically and rebuilds a matrix from its top singular value.

import numpy as np
A = np.array([[3.,1.],[1.,3.]])
vals,vecs = np.linalg.eigh(A)        # symmetric: real values
print(vals)                            # [2. 4.]
U,S,Vt = np.linalg.svd(A)
print(S)                               # [4. 2.]
print(vecs[:,-1] @ A @ vecs[:,-1])   # 4.0
