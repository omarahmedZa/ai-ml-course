Attention: a soft lookup

You can compute scaled dot-product attention by hand for two tokens and explain the Q/K/V roles.

Why this matters

Attention is the single mechanism behind every LLM you have used. It is also, underneath, topic 1: dot products, normalised, used as weights.

The one core idea

Each token asks a question (query), every token advertises what it offers (key), and the best matches donate their content (value). Matching is a dot product; donation is a weighted average.

How it actually works

VectorRoleAnalogy
Q (query)What this position is looking forSearch query
K (key)What this position offersDocument title / index
V (value)What this position passes onDocument body
Attention(Q,K,V) = softmax( QKᵀ / √d_k ) V
  • Scores: QKᵀ gives every query–key dot product. That is a similarity matrix of shape n × n.
  • Scaling by √d_k: dot products of d-dimensional vectors grow like √d. Without scaling, softmax saturates and gradients vanish.
  • Softmax turns each row into a distribution summing to 1 — competitive attention, not independent gates.
  • Weighted sum: each output is a blend of all values, weighted by relevance.
  • Self-attention: Q, K, V all come from the same sequence. Cross-attention: Q from the decoder, K and V from the encoder.
  • Cost: O(n²d) — doubling the context quadruples the score matrix. That is why long context is expensive.

Worked example

1. Two tokens, by hand

Query q = [1, 0]; keys k₁ = [1, 0], k₂ = [0, 1]; values v₁ = [10, 0], v₂ = [0, 10]; d_k = 2.

StepComputationResult
Raw scoresq·k₁ = 1, q·k₂ = 0[1, 0]
Scaled÷ √2[0.707, 0]
Softmaxe⁰·⁷⁰⁷ = 2.028, e⁰ = 1[0.670, 0.330]
Output0.67(10,0) + 0.33(0,10)[6.70, 3.30]

Token 1 matched perfectly, so it dominates — but token 2 still contributes 33%, because softmax never assigns exactly zero. Attention is graded, not discrete.

2. Why scale?

With d = 64 and random unit vectors, scores have standard deviation ≈ 8. After softmax, the largest score can reach 0.999 and the rest are ~0: the gradient through softmax collapses. Dividing by √64 = 8 restores unit-scale logits.

The trap

Most common wrong mental model

"Attention weights explain the model's decision." They redistribute information for the next layer; a high weight does not mean causal importance. Topic 32 shows why this claim fails empirically.

Second trap: thinking attention has memory or recurrence. It has neither — position must be injected explicitly (topic 27), and every token is processed independently per layer.

Retrieval check

  1. Why divide by √d_k rather than by d_k?
    Answer

    A dot product of d independent terms has variance proportional to d, so its standard deviation grows like √d. Dividing by √d normalises the standard deviation, not the variance.

  2. In self-attention, where do Q, K and V come from?
    Answer

    All three are learned linear projections of the same input sequence — three different weight matrices applied to the same tokens.

  3. Why is attention cost quadratic in sequence length?
    Answer

    Every token scores against every other token, producing an n × n matrix. Doubling n quadruples both computation and memory.

Build it in Colab

Runnable, NumPy-only, no setup: open the notebook in Colab · local copy. The cell prints numbers, not pictures — change one value and rerun to see what breaks.

import numpy as np
def softmax(z):
    e = np.exp(z - z.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)
Q = np.array([[1., 0.]])
K = np.array([[1., 0.], [0., 1.]])
V = np.array([[10., 0.], [0., 10.]])
