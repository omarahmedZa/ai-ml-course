TD error — target minus estimate

You can compute a TD error and the new Q value, and say why α rarely equals 1.

Where this sits

Q(s,a) ← Q(s,a) + α[ target − Q(s,a) ]

Topic 22 · the update term is lit; the estimate being nudged stays dim

An update has two numbers: where the estimate is, and where the evidence says it should be. The target is r + γ max Q(s′,a′). The bracket is the TD error — the gap between them, signed.

TD stands for temporal difference: the difference between a prediction made now and a slightly better prediction made one step later.

A nudge, not a replacement

α (alpha) sits between 0 and 1 and is the fraction of the gap you close in one update. α = 1 jumps straight to the target; α = 0 learns nothing at all. Values like 0.1 are chosen so one sample moves the estimate a little, not all the way.

The arithmetic of one update

Take Q = 0.5, r = 1, γ = 0.9, max Q′ = 0.8 and α = 0.1. The target is 1 + 0.9 × 0.8 = 1.72. The error is 1.72 − 0.5 = 1.22, and the move is 0.1 × 1.22 = 0.122. New Q: 0.622.

Why not jump all the way

The target is itself an estimate, built from another estimate that is also wrong. Jumping to it copies its noise whole. A small α averages many noisy targets, which is the same trade you made with the learning rate in topic 2: speed against stability.

The error is not the reward

A zero TD error does not mean the value is right. It means the two estimates agree. Two wrong numbers can agree perfectly, and no further update will separate them — which is why exploration and a slow α both matter.

Check the last two rows

0.5 × 1.22 = 0.61, and 0.5 + 0.61 = 1.11. The same evidence now moves the estimate five times as far. With α = 1 it would land exactly on 1.72 and inherit every bit of that target's noise.

The trap

Most common wrong mental model

"The TD error measures how wrong the reward was." The reward is observed and exact; the error is between two predictions. It measures surprise, not correctness.

Correction: a large positive error says the outcome was better than expected, not that the outcome was good. The sign tells you which way to move; the size tells you how far.

The tell: change only the next-state estimate and the error moves while no new reward has arrived. Nothing about the world changed — only the table's opinion of it.

Retrieval check

  1. Target 1.72, Q = 0.5. What is the sign of the TD error, and which way does Q move?
    Answer

    Positive: 1.72 − 0.5 = +1.22, so Q rises. A negative error would mean the estimate was too optimistic and gets pulled down.

  2. What happens to the TD error as the estimate converges?
    Answer

    It shrinks toward zero, because the target is built from estimates of the same table. At the fixed point every update is target = Q, so further samples change nothing.
