The Transformer block

You can name every sub-layer, its purpose, and why residual + LayerNorm are required.

Why this matters

"Transformer" is not one clever idea; it is four ordinary ideas stacked in a specific order. Knowing the order lets you read any architecture diagram and any config file without guessing.

The one core idea

A block is attention (mix information across tokens) plus FFN (process each token), each wrapped in a residual connection and normalisation. Stack 96 of them and you have GPT-3's body.

How it actually works

x → x + MHA(LN(x)) → x + FFN(LN(x)) (pre-LN form)
Sub-layerJobShape
Multi-head attentionEach head learns a different relation; outputs concatenated and projectedn×d → n×d
Feed-forward (FFN)Per-token nonlinear transform; where most parameters lived → 4d → d
Residualx + f(x): gradient highway, preserves informationn×d

Positional encodingInjects order — attention itself is permutation-invariantn×d
  • Multi-head: d_model = 512, 8 heads → each head works in 64 dimensions. Splitting lets one head track syntax and another track coreference, without increasing total cost.
  • FFN: Linear(d, 4d) → GELU → Linear(4d, d). At d = 512 that is ~2.1M parameters per block — two-thirds of the block.
  • Causal mask: a lower-triangular mask sets future scores to −∞ before softmax, so token t cannot see t+1. Without it, next-token prediction is trivial and useless.
  • Pre-LN vs post-LN: pre-LN (norm inside the residual branch) trains more stably at depth and is the modern default.

2. The mask, in one row

Token 3 attends to scores [s₁, s₂, s₃, −∞, −∞]. After softmax, tokens 4 and 5 receive exactly 0 probability. Remove the mask and the model can copy the answer from the future — training loss collapses to ~0 and generation produces gibberish.

The trap

Most common wrong mental model

"Attention makes the model order-aware." It is permutation-invariant by construction: shuffle the tokens and the outputs shuffle with them. Order comes only from positional encodings, which is why they are not an optional extra.

Second trap: assuming LayerNorm and BatchNorm are interchangeable. LayerNorm normalises across features within one token, so it works identically for a batch of 1 and a batch of 1,000 — essential for variable-length generation.

Retrieval check

  1. Why does the FFN hold most of the parameters even though attention gets the attention?
    Answer

    It expands to 4d and back, twice the matrices of the attention projections at 4× the width: 2·d·4d versus 4·d².

  2. What happens to next-token prediction if the causal mask is removed?
    Answer

    The model sees the target token in its own input, so the loss goes to near zero during training. At generation time the future is absent, and quality collapses.

  3. Why is pre-LN preferred for very deep transformers?
    Answer

    The residual path stays unnormalised, so gradients flow cleanly to early layers. Post-LN requires careful warmup and still destabilises beyond a few dozen blocks.
